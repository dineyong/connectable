## 데이터 흐름과 재생성

`data/site/content-v2.json` → `python3 web/derive-site-content.py` → `web/site-content-v2.js` → 브라우저 카드/상세.

CSP `connect-src 'none'`를 유지하기 위해 fetch 대신 same-origin 정적 JS 파생 자산을 로드한다. 기준 JSON은 수정하지 않는다. 파생 자산은 필요한 표시 필드만 투영하며 내부 source_file/행 해시/로컬 절대 경로와 노드·포트 등 원본 연구 구조를 제외한다. 헤더 주석의 SHA-256으로 현재 JSON과 일치 여부를 확인할 수 있다. 콘텐츠 변경 후 화면 담당 생성기를 다시 실행해야 한다.

HTML 값은 텍스트 이스케이프하고 출처 링크는 인증정보 없는 HTTPS만 허용한다. 새 탭에 noopener/noreferrer를 사용한다. 광고 코드·임의 제휴 URL·외부 폰트·분석·게시/계정 서버는 없다. noindex/nofollow 및 기존 로컬 서버 보안 헤더를 유지했다.

```sh
python3 web/derive-site-content.py
node --check web/site-v2.js
npx playwright test site-v2.spec.js review.spec.js --workers=2
python3 -m unittest discover -s tests -q
git diff --check
```

기존 서버 미리보기: http://127.0.0.1:8873/ . 이전 목업: /legacy.html . 내부 검토: /review.html . 자동 브라우저 테스트는 기존 설정의 별도 8874 서버를 사용한다.

## 기존 테스트 경로 충돌

`tests/e2e/mockup.spec.js`는 beforeEach와 일부 검사에서 `/`를 열고 이전 입력 폼·사례 카드를 기대한다. 새 구매 가이드 홈은 의도적으로 다른 화면이므로 해당 스위트는 현 `/`와 충돌한다. 실제 대표 검사:

`npx playwright test mockup.spec.js --project=desktop --grep 'required fields' --timeout=1500 --max-failures=1`

기존 ‘확인할 연결 조건 보기’ 버튼을 찾지 못해 FAIL했다. 기존 테스트를 억지로 수정하거나 실패를 숨기지 않았다. 모든 mockup 검사를 통과했다고 주장하지 않으며 이 초기 실행 시점에는 전체 `npm run test:e2e`가 녹색이 아니었다. 후속 통합 단계에서 기획 세션이 기존 스위트의 대상 경로만 `/legacy.html`로 이관했고, 전체 52개 통과를 전달했다. 이 화면 담당은 해당 기존 테스트를 수정하지 않았다. 새 스위트에서는 /legacy.html의 실제 입력 폼과 /review.html 진입을 확인했다.

## 후속 통합 수정: 동일 원문 그룹과 모니터 설명

기획 세션의 통합 검수에서 PUR-009/UQ-0009의 동일 원문 중복을 확인했다. 기준 JSON과 연구 기록 38개 및 정적 파생 데이터는 변경하지 않았다. 브라우저에서 인증정보 없는 HTTPS 원문 URL을 정규화하고, 해시·utm_*·fbclid/gclid 추적 파라미터·끝 슬래시를 제거해 그룹화한다. 의미 있는 쿼리 파라미터는 보존하고, 유효한 원문 URL이 없는 기록은 ID별로 분리한다. 사용자/사건 동일성 추정은 수행하지 않는다.

전체 피드는 **37개 원문 그룹 · 연구 기록 38개**를 표시하며 하나의 원문당 카드 하나를 렌더링한다. PUR-009 카드에는 동일 원문 연구 기록 2개와 두 ID가 표시된다. 상세에서 PUR-009↔UQ-0009 상호 링크를 제공하고 각 기록의 구성·관측·결측을 그대로 열람한다. 필터/검색에 맞는 기록을 대표로 표시하며 검색 결과 건수는 일치 원문 그룹 수와 일치 연구 기록 수다. 필터에서 한 기록만 일치해도 동일 원문의 다른 기록을 상세에서 열 수 있다. 원문 그룹/연구 기록 수를 사용자 수·독립 사건 수로 설명하지 않는다.

모니터 섹션은 ‘공식 기능을 비교하고, 연결 후기는 별도로 살펴보세요.’로 수정하고, 현재 정확히 연결된 후기가 없다는 상태를 본문에 명시했다. 제품 방향은 유지하며 자료 연결이 없는 기능을 이미 제공하는 것처럼 설명하지 않는다.

후속 검사 명령: `npx playwright test site-v2.spec.js --workers=2 --output=/tmp/connectable-v2-dedupe-results`. 초기 중복그룹 변경 후 20개 PASS. 정규화 경계 회귀와 최종 문구 변경을 포함한 결과는 아래에 기록한다. 기존 테스트/기준 JSON/연구 기록/보존본/다른 소유 파일은 수정하지 않았다.

최종 새 홈 검사: 데스크톱/모바일 **22개 PASS** (11개 흐름 × 2 환경, 9.9초). 홈/상세 axe 위반 0건, 콘솔 오류 없음, 기존 보안·탐색 검사 유지. 추가 회귀는 전체 37카드와 38기록 표시, 두 관측의 상세 이동, 개별 ID 검색과 관련 기록 보존, URL 추적/해시/슬래시 정규화를 검사한다. 스크린샷 3개도 현재 그룹 표시와 PUR-009 중복 그룹 상세로 갱신했다.

## 2026-10-09 벤치마크 후속 구현

사용자 승인 범위에서 README·제품방향 v2·경쟁 UI 벤치마크를 읽고 현재 웹 전체 16개 파일을 `archive/site-v2-20261009/`에 먼저 복사했다. SHA-256 manifest를 추가했으며 기존 10월 8일 보존본도 유지했다. 이전 legacy/review 자산과 화면은 변경하지 않았다. 이 절이 현재 화면 구현·검증·의존성 상태다.

### 결과와 데이터 연결

데이터 담당의 배치 완성 통지와 `SITE_CONTENT_MONITOR_BATCH_1_REPORT.md`·`monitor-batch-1-sources.json`을 대조한 뒤 기준 JSON에서 정적 JS를 재생성했다. 현재 모니터는 6개이며 V32UE·27ULD950·MD271UL과 PUR-001/005/006/014의 모델 수준 연결 4개를 표시한다. 실물 SKU·지역 변형·리비전 일치나 맥북 호환 승인이 아니다. 공개 UNKNOWN·검토 대기와 원래 관측·결측·상업성 맥락을 유지한다. 기준 JSON·원본 연구 기록은 화면 담당이 수정하지 않았다.

`web/derive-site-content.py`의 표시 투영에 optional variant/capabilities/monitor_links를 추가했다. 신규 capability 상태와 공식 fact를 함께 대조하며 기존 모델은 실제 공식 feature의 명시된 근거를 사용한다. 영상 지원은 명시된 USB-C 영상 기능을 기준으로 하고 DP protocol UNKNOWN을 추정하지 않는다. 충전 필터는 공식 공급 표기가 확인된 자료를 포함하되 전력 W 미상을 숫자로 채우지 않는다. 특히 27ULD950의 PD65 이름을 65W 확정 공급으로 변환하지 않았다. KVM·스피커·높이 조절은 명시 근거가 있는 27ULD950만 해당 필터에 포함된다. UNKNOWN은 미지원이 아니다.

### 방문자 흐름

- 후기 카드 제목은 기존 관측의 사실 요약을 사용한다. 연구 ID를 제목 앞에 표시하지 않으며 상세의 접을 수 있는 ‘근거 기록 ID와 검토 상태’에 원본 ID·원래 제목·검토 상태를 보존한다. 카드에는 장비와 연결 경로가 함께 보인다.
- 관측 구성의 role=OBSERVED에서 NO_SIGNAL/DEGRADED/INTERMITTENT가 있으면 ‘문제 관측 포함’, NORMAL이 있으면 ‘사용 관측 포함’, 그 외에는 ‘연결 기록’으로 표시한다. 일반 성공/해결로 확정하지 않는다. ‘해결 후기’ 분류는 문제→최종 해결의 연속 근거가 충분하지 않은 기록에 생성하지 않았다. 별도 유형 필터를 추가하지 않고 공식 지원 필터만 추가했다.
- 모니터 상세는 제품 요약 → 공식 기능·부가기능 → 동일 표시 모델의 연구 기록 → 주의·결측 → 케이블·설정 → 관련 가이드 → 근거 ID·출처 순서다. 관계가 없는 모델은 후기 없음 안내를 유지하며 모델 수준 연결과 실물/SKU 미확정을 본문에서 구분한다. 연결 기록에서 공식 모델로 되돌아갈 수 있다.
- 두 제품을 비교 담기 체크박스로 선택한다. 하나만 선택하면 비교 버튼이 비활성화되고 두 개 선택 후 다른 제품은 선택할 수 없다. 선택 해제와 선택 비우기를 제공하며 검색/필터 변경 시 비교 선택은 유지된다. 선택 목록과 비교 버튼이 하단 바에 표시된다. 브라우저 저장소에는 저장하지 않는다.
- 비교표는 동일 항목의 패널 해상도·Hz / 입력 포트별 해상도·Hz / USB-C 영상 / 공식 PD 공급 전력 상한·표기 / KVM / 스피커 / 높이 조절 / 동일 모델 기록 / 지역·검토 상태를 나란히 보여준다. 공급 포트별 요약을 보존하므로 downstream 15W를 영상 upstream 90W와 합치지 않는다. 미상 값에는 UNKNOWN·아직 확인되지 않음·미지원 아님을 명시한다. 제품 상세와 연구 기록 및 출처로 이동한다.
- 모바일 비교표는 표 내부 가로 이동과 고정 항목명, 이동 안내를 제공한다. 가로 이동 영역은 키보드로 초점을 받을 수 있다. 문서 전체에 가로 스크롤을 만들지 않는다.
- 가이드 상세에는 짧은 요약, 문단별 목차, 확인 항목 본문, 관련 제품·연결 기록·출처가 있다. 목차 버튼은 해당 항목으로 이동하며 초점도 전달한다. 기존 문단을 새 구매 추천 결론으로 바꾸지 않았다.
- 중복 그룹 규칙과 PUR-009/UQ-0009 양쪽 상세 열람은 유지했다. 전체 37개 원문 그룹·38개 연구 기록이며 사용자 수·독립 사건 수가 아니다.

사진·가격·평점·추천 순위·구매 URL·실제 광고·계정/게시 서버는 추가하지 않았다. noindex와 CSP connect-src none을 유지했다. 공식 제품 페이지 링크는 근거 출처이며 제휴 구매 버튼을 만들지 않았다.
