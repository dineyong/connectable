# 프로젝트 작업 지침

> 2026-10-10: 이 문서의 기능 범위·타깃·개발 순서는 이전 기준입니다. 현재는 [제품 방향 v3](PRODUCT_DIRECTION_V3.md)와 [진행 계획](MONITOR_COMPARISON_V3_ROADMAP.md)을 우선합니다. 기존 출처·안전·보존 원칙과 아래 역사적 내용은 유지합니다.

## 프로젝트명

연결돼? — 노트북·모니터 호환성 플랫폼

프로젝트명은 작업용 가칭이다. 서비스명과 도메인은 별도 검토 후 확정한다.

## 목표

한국 사용자가 자신의 노트북, 모니터, 케이블, 허브 또는 독 조합을 입력하면
공식 사양과 검증된 실사용 사례를 근거로 연결 가능 여부, 최대 해상도와
주사율, 충전 조건, 멀티모니터 제한 및 필요한 주변기기를 확인할 수 있는
실제 운영 웹사이트를 구축한다.

## 현재 단계

개발 전 조사·설계 단계다. 본격적인 UI 및 기능 개발보다 아래 작업을 먼저
완료한다.

1. 실제 사용자 질문 100건 수집 및 분류
2. 제조사·표준기관 공식 출처 목록 구축
3. 제품 및 근거 데이터 구조 설계
4. 호환성 판정 규칙 정의
5. 초기 맥북·모니터·독 데이터 구축
6. 검증 조합과 테스트 케이스 작성
7. MVP 명세 확정

## 작업 원칙

- 모든 작업 결과는 Git으로 버전 관리한다.
- 의미 있는 단계마다 작은 커밋을 만들고 원격 저장소에 push한다.
- `main`은 검증된 기준선만 유지하고 조사·기능 작업은 별도 브랜치에서 한다.
- 기존 파일과 사용자 변경사항을 확인한 뒤 수정한다.
- 제품 사양은 공식 출처 URL과 확인일 없이 확정하지 않는다.
- AI가 추측한 호환성 정보를 확정 데이터로 저장하지 않는다.
- 불확실하면 `UNKNOWN`, 출처가 충돌하면 `CONFLICT`로 남긴다.
- 접근 제한 우회, 무단 대량수집 및 약관 위반 크롤링을 하지 않는다.
- 자유 댓글과 구조화된 연결 성공·실패 사례를 분리한다.
- 제휴링크는 문제 해결에 필요한 제품에만 표시하고 광고 관계를 고지한다.
- 빈 조합이나 근거가 부족한 페이지를 SEO 목적으로 대량 생성하지 않는다.

## 역할

- 사용자: 제품 방향, 우선순위, 최종 승인
- Codex: 조사 검증, 데이터·규칙·시스템 설계, 구현, 테스트, Git 관리
- 생성형 AI 보조: 출처 후보 발굴, 분류, 중복 탐지, 문구 초안

## MVP 범위

- Apple Silicon MacBook Air 및 MacBook Pro
- 주요 외장 모니터 약 30개
- USB-C, Thunderbolt, HDMI, DisplayPort
- 케이블, 어댑터, USB-C 허브, Thunderbolt 독, DisplayLink
- 해상도·주사율·외장 화면 수·PD 충전 판정
- 실제 연결 성공·제한·실패 등록과 관리자 승인
- 조합별 근거 및 제휴상품 표시

Windows 노트북 전체, 데스크톱, TV·콘솔, 가격 추적은 MVP에서 제외한다.
