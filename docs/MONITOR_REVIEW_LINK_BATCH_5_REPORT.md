## 조사 및 반영

추가 원글은 독일어 문제 질문·본인 관측 사례다. 긍정 추천이나 최종 실패로 표현하지 않는다. 작성자 본인 원글만 관측 근거로 사용하고 타인의 패널·교체 조언은 실제 수행 결과로 저장하지 않았다. 사이트 광고 배너 고지로 `commercial_context=PRESENT`이며 작성자 협찬·제휴 상세는 미확인이다. 공식 사양·한국 SKU 동일성·호환성 승인 근거로 승격하지 않는다. 사용자명·닉네임·연락처·본문 전체·사진·영상·점수를 복제하지 않는다.

`checked_model`은 카탈로그 표시명 `S32CG554EU (LS32CG554EUXEN)`을 사용하고 원문에서 직접 확인한 식별 근거는 전체 SKU `LS32CG554EUXEN`임을 notes/evidence_location에 보존한다. 제품군 이름만으로 다른 지역 SKU를 추정한 매칭이 아니다. 초기 후보의 SKU 단독 checked_model은 기존 검증기에 거부됐으며, 원본 SKU·제품을 바꾸지 않고 카탈로그 표시명과 확인 근거를 분리 기록했다.

## 최소 플랫폼 보강

[링크 원본](../data/research/monitor-review-links.json)과 [정확 URL 검토 바인딩](../data/research/monitor-review-link-bindings.json)에1건만 추가했다. 블로그로 오분류하지 않도록 `Forum` 유형과 커뮤니티 표시를 최소 지원한다. 개별 블로그와 동일하게 정확 원문 URL·제품·확인 모델 등록이 없으면 거부한다. 기존 URL 보안 규칙·RTINGS 고정 경로·퀘이사존 원본 참조 계약을 유지한다.

[Python 회귀](../tests/test_monitor_review_links.py)에 Forum1개 테스트를 추가했다. 등록 전 `site host mismatch`로 실패함을 확인하고, 지원 후에는 정확 등록 허용·등록 없음·다른 원글·위장 호스트·다른 모델 재연결을 구분하여 검사했다. [브라우저 회귀](../tests/e2e/monitor-review-links.spec.js)는 커뮤니티 라벨과 새 창 보안 속성, 미등록·위장 링크 숨김을 기존 플랫폼 검사에 추가했다. UI 전면 재설계나 댓글 기능은 추가하지 않는다.
