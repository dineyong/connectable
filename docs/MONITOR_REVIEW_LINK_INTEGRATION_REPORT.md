# 외부 후기 링크 및 공식 근거 병렬 배치 통합

2026-10-11 · `codex/monitor-purpose-design` · 기준 `221d072`.

## 결과

사용자가 외부 링크 새 창 동작과 세션별 병렬 작업을 승인했다. [세션 분담](PROJECT_SESSIONS.md)에 따라 공식 사양, 후기 원문, 화면을 분담하고 통합 검증한다.

- 사양: MD271UL·M27Q rev.1.0 Adaptive-Sync 지원2항목 추가. VRR 범위는 추정하지 않음. M28U·M32U 한국 공식 페이지 연결 확인 기록, 국내 SKU·보증 미확인 유지.
- 충돌: MD271UL 무게에 설명서/웹 차이를 추가 표시. 기존 MAG 등의 충돌과 원래 수치를 보존.
- 후기: 4제품5링크(전문 리뷰4, 개인 사용기1)를 제품 상세 대화상자 및 정적 문서에 연결. 본문·사진·점수 복제 없이 직접 작성한 짧은 안내와 원문 링크만 사용.
- 외부 이동: `target="_blank"` 및 `rel="noopener noreferrer"`. 원문이 새 탭/창으로 열린다는 안내 포함. 실제 창/탭 선택은 브라우저 설정에 따름. 기존 공식 출처와 뉴스 링크도 같은 속성을 사용한다.
- 데이터: 후기 원본과 파생 표시를 별도 파일로 관리. 정확 모델·출처·URL 경로·기존 후기 참조 검증 후 생성, CI에 생성물 일치 검사 추가.

## 진행 규모와 대기 기준

사양 자료는30종, 초기 후기 링크는4종에만 있다. 남은26종의 후기 링크가 없다는 사실은 실제 후기가 없다는 의미가 아니다. 접근·모델 검토를 완료한 자료만 순차 추가한다. 검색 요약으로 링크의 내용을 추정하지 않는다.

사양 결측은276에서274로 감소했다. 그중120개는 각30종의 `korean_sku_identity`, `warranty_korea`, `per_input_simultaneous_conditions`, `physical_test_results`이다. 나머지154개도 공식 문서에 미기재하거나 모델 범위가 불확실할 수 있어 웹 검색으로 전량 해소를 보장하지 않는다. 이 숫자는 출시 작업 개수나 완료율이 아니다.

| 대기 항목 | 재개 조건 |
|---|---|
| 한국 SKU·국내 보증 | 정확한 판매 품번·리비전·구성·보증 적용 범위에 대한 공식 근거 |
| 동시 입력·실측 | 입력 조합별 공식 제한 또는 별도 검토된 실측 자료. 일반 포트 최대값으로 대체하지 않음 |
| 공식 자료 충돌 | 제조사 정정·지역/리비전별 설명. 임의로 하나를 선택하거나 평균하지 않음 |
| 미기재 부가기능 | 정확 모델 설명서의 명시. 문서에 없다고 미지원으로 처리하지 않음 |
| 후기 확대 | 공개 원문 직접 확인·정확 모델 연결·정책 범위 확인. 불확실한 접미사/리비전은 자동 연결 금지 |

같은 URL을 연속 조회하는 소규모 배치는 보류할 수 있다. 신규 근거가 확보된 항목을 모아서 반영·통합 테스트·CI를 수행한다. 사양 결측0개를 사이트 개발 완료의 필수 조건으로 삼지 않는다.

## 보존과 제한

기존 후기24건·질문 코퍼스·원본과 사용자의 미커밋 변경은 보존한다. 새로운 후기 링크가 한국 SKU 승인·호환성 판정·제품 별점으로 승격되지 않는다. RTINGS제휴 있음, 퀘이사존 광고성 미확인으로 표시. 현재 외부 원문 정책 재사용 허가나 대량 자동 수집 허가를 주장하지 않는다. 링크 제거 요청 대응·정책 검토는 공개 운영 전에 점검한다.

main 병합·공개 배포·광고 활성화는 수행하지 않는다. 지금 추가 사용자 결정은 없다. 공개 범위·도메인·이미지 사용권·수익화 실제 연결은 기존 결정 대기 목록을 따른다.
