# connectable 조사 기반 사이트 목업

2026-10-07 사용자의 목업 완료 요청에 따라 [ADR-007](DECISIONS.md)을 기록했다.
현재 브랜치 `research/question-corpus-foundation`에서 기존 조사 자료를 보존하며 제작했다.

## 완성 범위

- 한국어 랜딩 페이지, 노트북·허브·두 화면 연결 그림, 서비스 원칙 안내
- 맥북 모델·칩·연결 방식·화면 수·목표 해상도·주사율·충전 입력
- 입력 누락 안내 및 구성별 확인 필요 조건 요약
- 정식 v2 사례 16건의 결과 필터, 기기·문제 검색, 더 보기
- 작성자 결과·개별 관측·결측·원문 URL·확인일을 담은 상세 대화상자
- 모바일 단일 열 배치, 폼 라벨·초점·키보드 상세 닫기·감소된 애니메이션 지원

확정 호환 판정이나 최대 성능을 제공하는 운영 제품은 아니다. 공식 자료 대조 전 상태를
결과와 사례에 표시한다. 칩 옵션은 입력용 예시이며 제품 목록·존재하는 모든 모델·공식 지원 조건의 기준이 아니다.
목업에는 브라우저 입력 저장, 네트워크 전송, 로그인, 결제, 관리자, 상품 추천, 제휴 링크가 없다.
사례 카드의 성공은 해당 작성자 결과이며 공식 호환 승인이 아니다.
데스크톱·Windows 연구 사례 표시도 MVP 지원 제품군을 확장한 결정이 아니다.

## 실행

```sh
python3 scripts/build_mockup_cases.py
python3 -m http.server 8873 --bind 127.0.0.1 --directory web
```

브라우저에서 http://127.0.0.1:8873 을 연다. Python 표준 라이브러리 외 설치가 필요 없다.
재시작 후 미리보기 서버가 종료돼 있으면 위 명령으로 다시 실행한다.
`web/index.html`을 직접 열어도 기본 인터랙션이 동작한다.
Google Fonts를 사용하며 네트워크가 없으면 로컬 sans-serif 글꼴로 대체된다.

[첫 화면 검수 스크린샷](screenshots/connectable-mockup.png)을 보존했다.

## 데이터와 파일

[정식 JSONL](../data/research/user_questions_v2.jsonl)은 변경하지 않는다.
[scripts/build_mockup_cases.py](../scripts/build_mockup_cases.py)가 읽기 전용 [web/cases.js](../web/cases.js)를 만든다.
파생 자산을 직접 수정하지 않으며 원문 본문·닉네임을 새로 수집하지 않는다.
HTML·CSS·JavaScript는 [web](../web/index.html)에 있으며 UI 제목은 편집 요약이지 사양 주장이나 새 연구 데이터가 아니다.

## 검증과 한계

기존 122개와 파생 원본 일치·재생성·공식 판정 비생성·HTML 삽입 방지 검사 4개, 총 126개 테스트 PASS.
기존 v1/v2 검증을 유지하며 원본 코퍼스·스키마의 작업 시작 커밋 대비 바이트 보존을 검사한다.
실제 브라우저에서 연결 입력, 충전 조건, 미해결 필터, 상세·출처 링크, 없는 검색어 빈 상태를 확인했다.
390px 모바일 폭에서 가로 넘침 없이 단일 열 배치를 확인했고 데스크톱 스크린샷도 검수했다. 브라우저 검사는 서버 응답과 JavaScript 실행을 함께 확인한다.

입력에서 생산한 결과는 조건 체크리스트다. 공식 판정 구현·공식 사양 데이터 구축·남은 4건 마이그레이션과
21~100번 수집은 완료되지 않았다. 실제 운영·공개 승인을 의미하지 않는다.
이 단계에서 사용자 입력을 저장하지 않으므로 재방문 시 선택은 초기화된다.
