# 용도 선택 결과 안내와 남은 작업

2026-10-11 · codex/monitor-purpose-design · 기준 d0775ab.

## CI 확인

기준 커밋 d0775ab의 [GitHub CI](https://github.com/dineyong/connectable/actions/runs/38115290092)는 completed/success로 직접 확인했다. 이번 변경의 CI와 구분한다.

## 변경

용도 선택만으로 상품 목록에 자동 이동하지 않는다. 용도 카드 아래 안내 칸에 선택한 용도, 사양 조건, 현재 검색어·브랜드까지 반영한 상품 수를 표시한다. 사용자가 결과 버튼을 눌러야 상품 목록으로 이동하고 키보드 초점을 전달한다. 0개일 때 조건 변경 안내를 표시하고 대체 상품을 만들지 않는다. 전체 초기화 또는 수동 사양 변경으로 용도 선택이 해제되면 안내도 숨긴다.

## 남은 개발 작업과 사용자 결정

| 작업 | 개발 준비 | 사용자 결정/입력 |
| --- | --- | --- |
| 공개 제품 정보 | SKU·부분 검토 상태별 공개 대상 정리, 정정 경로 | 공개 범위와 최종 자료 검토 |
| 제품 이미지 | 권한 있는 이미지로 대체, 최적화·대체 텍스트 | 이미지 원본/사용 권한 |
| 뉴스 운영 | 수집 실패·중복·오래된 기사 처리, 갱신 자동화 | 사용할 출처·갱신 주기·API 발급 및 검토 담당 |
| 반응·댓글 | 공개 저장소·스팸 방지·삭제 절차 | 이모지 반응만 먼저 출시할지, 댓글도 운영할지 |
| 출시 | 실제 도메인 기준 SEO·사이트맵·검색 등록·최종 접근성 점검 | 도메인·호스팅·공개 시점 |
| 쿠팡 | 등록된 사이트에 서버 API·배너 연결 후 검증 | 사이트 등록과 배너 정보, 키는 안전한 환경 설정 |

권장 순서는 공개할 제품·이미지 확정 → 이모지 반응 중심 초기 운영 여부 결정 → 뉴스 운영 방식 → 도메인/배포 → 광고 연결이다. 현재 로컬 기능 완료를 공개 서비스 완료로 표시하지 않는다. 원본 데이터와 기존 사용자 변경은 보존한다.

## 검증

데스크톱·모바일에서 선택 후 초점 유지, 버튼을 통한 이동, 실제 개수 일치, 0개 결과와 초기화를 확인했다. 로컬 브라우저에서 문서·사무 11개 안내를 직접 확인했다. [화면 기록](screenshots/purpose-result-preview.png).

- 관련 브라우저 검사 18개 통과.
- 로컬 HTML/메타데이터/공개 보류 검증 통과.
- 정적 모니터 문서 30개 생성 일치 검사 통과.
- Python 및 원본 데이터는 이번 변경 대상이 아니므로 전체 Python 재실행은 생략했다. 직전 로컬 결과는 556개 통과이며 이번 실행 결과로 간주하지 않는다.

- 전체 브라우저 테스트 `npm run test:e2e -- --workers=2`: 184개 통과(사용자 미커밋 테스트 포함 로컬 결과).
- `git diff --check`: 통과. 원본 data/schema 변경 없음.
