# 제품 이미지 사용권 조사 · 2026-10-15

## 조사 범위와 결론

Connectable은 한국어 모니터 사양 비교·구매 가이드 사이트이며 광고·제휴 수익화를 예정한다. 공개 제조사 홈페이지나 내려받기 버튼의 존재만으로 이 사이트의 이미지 재게시 권한을 인정하지 않았다. 제조사 8곳의 공개 이용 조건 또는 미디어 경로를 제한된 범위로 직접 열어 확인했다. 이는 30개 개별 사진의 권리를 모두 검증했다는 뜻이 아니다.

**상업 비교 사이트에서 쓸 수 있는 정확한 제품 이미지 후보 0건, 실제 사진 적용 0건.** 삼성 한국 뉴스룸에는 자체 제작 이미지의 재사용 안내가 있지만, 현재 두 제품의 외국 지역 SKU와 동일한 사진·제작 주체를 연결하는 근거가 없다. 이미지 다운로드, 핫링크, 로그인, 신청, 약관 동의, 권리자 연락은 수행하지 않았다. 기존 CSS 형태 예시와 원본 데이터는 변경하지 않았다. 이 보고서는 공개 문서 조사 결과이며 법적 이용 가능성을 포괄적으로 보증하지 않는다.

## 미디어 경로와 접근 한계

- [ASUS Media Kit](https://press.asus.com/media/media-kit/)는 직접 열려 행사별 자료 목록을 확인했다. 개별 7개 제품 사진과 별도 상업 사용 조건은 확인하지 못했다. 미디어 키트라는 이름 자체는 허가 근거가 아니다.
- [Dell UK Media Library](https://www.dell.com/en-uk/dt/corporate/newsroom/media-library.htm)는 첫 직접 열기에서 경로가 열렸지만 이어진 내용 확인은 `403 Forbidden`이었다. 우회하지 않았다. 특정 모니터 사진·권리 조건을 확인했다고 기록하지 않는다.
- [Gigabyte Media Kit](https://www.gigabyte.com/press/media-kit)는 검색 후보였지만 직접 열기는 `Internal Error`였다. 검색 요약을 권리 근거로 사용하지 않았다.
- BenQ의 처음 조사한 `/en-us/policy/terms-of-use.html`, AOC의 `/us/terms-of-use`는 직접 열기 오류였다. 이후 공개 검색에서 찾은 다른 실제 정책 URL을 열었다. 반복 재시도·접근 제한 우회는 하지 않았다.
- `https://www.lgnewsroom.com/` 직접 열기는 `https://lgnewsroom.com/`로 이동해 베트남 축구 관련 제목·본문이 나타났다. 현재 공식 LG 이미지/사용권 근거로 채택하지 않는다. 소유권 변경·침해 여부나 원인은 확인되지 않았으므로 단정하지 않는다. 새로운 공식 LG 미디어 경로는 `lg.com`에서 연결 관계를 확인한 뒤 별도 조사해야 한다.

## 다음 최소 조치

현재 화면의 형태 예시는 계속 실제 제품 사진과 구분한다. 사진이 첫 출시의 필수 조건인지는 사용자 결정 사항으로 남긴다. 권리자가 제공한 비교·광고·제휴 사이트 게시 허용 자료 또는 직접 촬영 자료가 생기면 다음 기록을 함께 검토한다: 제품 ID와 정확한 지역/색상/리비전, 원본 URL 또는 파일, 권리자, 허용 근거 URL/문서 위치, 확인일, 재게시·상업 범위, 출처 표기·수정·저장·기간 조건. 자료 확보나 연락을 이미 수행한 것처럼 보고하지 않는다.
