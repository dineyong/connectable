## 이번 세션 분담과 완료 범위

| 세션 | 구현·검증 대상 | 현재 경계 |
|---|---|---|
| 참여 | 제품별 300자 댓글 초안 저장/재열기/삭제, 저장 실패·손상·XSS 방어 | 이 브라우저에만 저장. 실제 공개 댓글·사용 후기·집계 아님 |
| 뉴스 UI | 승인 디자인, 목록 복귀, 저장 시각·오류·출처 상태 표시 | 기존 RSS 스냅샷 사용. 새 수집·실시간 운영 미실행 |
| 품질 | 현대 페이지 34개 HTML 링크·메타데이터·noindex·공개 구조화 데이터 경계 검사, CI 연결 | 외부 출처 재검증/사양 승인/실제 서비스 보안감사 아님 |
| 통합 | JavaScript 없이 접근하는 전체 30제품 목록, 세션 연결, 전체 테스트·기존 데이터 해시·시각 검수 | main 병합·공개 배포 없이 작업 브랜치만 push |

기능·탐색·콘텐츠의 로컬 미리보기는 사용자가 볼 수 있는 단계다. 실제 운영 완료율로 환산하지 않는다. 이전 조사 원본은 보존한다.

## 이번에 사용자 판단 없이 완료한 내용

1. 댓글은 서버 없는 최소 로컬 초안으로 구현하고 공개되지 않는다고 입력 근처에 표시했다. 저장 실패 때 성공으로 표시하지 않는다.
2. 뉴스 버튼은 저장된 목록을 다시 읽는 동작임을 명시한다. 현재 수집 프로세스 실행 여부나 실시간성을 추정하지 않는다.
3. 검색 화면이 작동하지 않아도 [전체 정적 제품 목록](../web/monitors/index.html)에서 모든 제품에 접근한다. 기존 제품 문서 내용은 변경하지 않았다.
4. 자동 품질 검사에서 발견한 scheme+netloc 우회(javascript:// 등)를 실패 테스트로 확인한 후 수정했다. 외부 사이트 자동 접속은 없다.
5. 새 디자인 기준을 최신 문서에 명시했다. 과거 연구·승인 정책은 폐기하지 않았다.

## 남아 있는 사용자 판단

| 결정 | 준비된 상태 | 결정 후 진행할 작업 |
|---|---|---|
| 디자인 사용감 | 데스크톱·모바일 동작과 테스트 완료 | 구체적인 사용감 피드백 반영 |
| 공개 범위·한국 SKU | 원본/문서 지역·미확인 표시 유지 | 제품별 검토 근거 기록; 자동 승인 금지 |
| 실제 댓글 운영 | 로컬 초안 UI·기본 안전 검증 완료 | 서버 저장, 신고/삭제 권한, 보관기간, 스팸 제한 및 운영 책임 확정 후 실제 서비스 구현 |
| 제품 이미지 | [사용권 검토](MONITOR_IMAGES_AND_GUIDES_REPORT.md); 실제 사진 0개 | 직접 촬영본 또는 사용 허가 자료를 모델과 대조 후 적용 |
| 도메인·운영 환경 | 정적 제품/가이드와 미리보기 검사 준비 | 환경·비용·권한·공개 승인 후 배포 및 검색 설정 |
| 광고·제휴 | 비교 순위와 분리, 실제 광고·링크 미활성 | 계정·상품 옵션·관계 고지 확인 후 연결 |

저장소·현재 브라우저에 입력한 값은 해당 브라우저 범위다. 공개 댓글처럼 다른 사람이나 기기와 공유되지 않는다. 로컬 데이터 손상 시 임의로 삭제하거나 덮어쓰지 않는다. 실제 운영의 인증·권한·개인정보 검토를 이 로컬 기능으로 대신하지 않는다.

## 통합 검증 결과

- Python: `python3 -m unittest discover -s tests -q` — **546개 통과**, 21.350초.
- 브라우저: `npm run test:e2e -- --workers=2` — **166개 통과**, 1.2분. 데스크톱·모바일 및 JavaScript 비활성 상태 포함.
- 로컬 166개에는 작업 시작 전 미커밋 테스트 14개가 포함된다. 이를 이번 커밋에 포함하지 않아 원격 예상은 152개다.
- 신규 로컬 품질 단위 테스트 17개, 정적 목록 단위 테스트 3개 포함.
- `python3 scripts/validate_local_site.py`, `python3 scripts/build_monitor_pages_v3.py --check`, `git diff --check`: 통과.
- 원본 data와 사용자 변경 4파일을 포함한 28파일 SHA-256: 시작 시점과 동일.
- 기존 제품 상세 30개: 이번 배치 변경 없음. 루트 정적 목록만 추가.
- 뉴스·댓글 데스크톱/모바일을 직접 시각 확인. 빈 초안 화면만 촬영했고 실제 브라우저에 샘플 댓글을 저장하지 않았다.
- 뉴스 초기 개별 접근성 2실패는 코드 수정 후 통과. 정적 검증기의 scheme+netloc/standalone JSON-LD @type 문제는 회귀 테스트 먼저 실패 재현 후 수정했다.

## 자동 검사의 한계

외부 URL 실시간 접근, 사진 권리 승인, 실제 SKU 동일성, 사용자 댓글 모더레이션은 자동 통과 대상이 아니다. CSS 참조 및 모든 JavaScript 런타임 링크는 정적 검사에 포함되지 않아 브라우저 테스트와 구분한다. JSON-LD 사용자 정의 context/별칭 전체 해석은 미지원이며 새로운 구조화 데이터 도입 때 별도 검토한다. 테스트가 서비스 정확도나 공개 보안감사를 대신하지 않는다.
