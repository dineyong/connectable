## 최소 변경

- [링크 원본](../data/research/monitor-review-links.json)에 직접 확인한1건 추가. RTINGS는 기존처럼 [검증기](../scripts/build_monitor_review_links.py)의 정확한 제품별 경로 목록에 해당1경로만 등록한다. 신규 플랫폼 바인딩 파일은 변경하지 않았다.
- 파생 링크 JSON/JS와 LG 해당 제품 정적 문서만 재생성했다. 화면 코드·디자인·제품 사양·질문 코퍼스·한국 SKU·공개 UNKNOWN 정책은 변경하지 않았다.
- [회귀 테스트](../tests/test_monitor_review_links.py)에 정확 -B 경로 허용·접미사 누락/다른 모델 경로 거부·다른 모델로 재바인딩 거부1개 추가. 경로 등록 전에는 `unreviewed model URL binding`으로 실패함을 확인한 후 정확 경로 등록만으로 통과했다. 검증 기준을 완화하지 않았다.
