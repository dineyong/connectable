# 디자인 A 로컬 구현 보고서

2026-10-10. 작업 브랜치 `codex/monitor-comparison-v3-local`, 시작 커밋 `a1aaa82`.

사용자는 디자인 1번 빠른 탐색형을 선택하고 사용자 검토가 필요하지 않은 로컬 작업을 계속 진행하도록 승인했다. 데이터 변환, UI 구현, 브라우저 검증을 별도 작업 단위로 분담했다. 기존 페이지를 교체하지 않고 새 페이지를 추가했다.

## 실행과 데이터 경로

- 로컬 홈: `http://127.0.0.1:8875/monitor-v3.html`
- 제품 예시: `http://127.0.0.1:8875/monitors/asus-pa279crv/index.html`
- 기존 8875 서버가 실행 중이면 새 파일을 바로 제공한다. 종료 후 정적 미리보기는 `python3 scripts/serve_mockup.py --port 8875`로 실행한다. 이 명령은 RSS 자동 갱신 서버가 아니다. 뉴스 갱신은 기존 `serve_tech_news_preview.py`의 별도 동작을 따른다.
- 원본 `data/research/monitor-expansion/official_specs.json` → 원본 검증 → `build_monitor_v3.py` → JSON/JS 표시 데이터 → 로컬 검색·필터·비교.
- 같은 원본 → `build_monitor_pages_v3.py` → 제품별 정적 HTML 30개. 모델명·사양표·조건·출처·확인일은 JavaScript 없이 읽힌다.

## 구현 범위와 경계

모델 30종·637 facts를 원본 그대로 유지했다. 크기·해상도·패널·패널 주사율의 확정적 표시값만 필터에 사용한다. USB-C 영상 필터는 명시된 DP Alt Mode 확인이며 커넥터/TB/충전만으로 영상 기능을 추정하지 않는다. 미확인 포함 옵션은 필터 조건의 확인된 충족과 구분한다. 공개 상태 UNKNOWN, 사람 검토 대기, 호환성 사용 NO를 유지한다.

한국 판매 SKU 동일성, 입력별 주사율과 패널 주사율, PD 공급과 소비전력, RATED/UP_TO를 보존한다. 상세에는 원문 값·단위·범위·근거 위치가 표시된다. 서술형과 구조화 값은 우열 점수로 만들지 않는다. 제품 이미지는 일반적인 모니터 일러스트이며 실물 사진이 아니다.

제품별 URL·고유 제목·설명·초기 HTML을 제공하지만 **검색 공개 준비 완료를 뜻하지 않는다**. 로컬 전체 noindex, 공개 도메인/canonical/sitemap/Product offers/평점 구조화 데이터는 생성하지 않는다. 광고·제휴 링크·외부 추적·공개 배포·main 병합을 하지 않았다. 영구 댓글 저장, 신고/운영자 검토와 사용자 계정도 범위 밖이다.

## 추가 자료와 다음 단계

닷의 자료는 아직 도착하지 않았다. 기존 퀘이사존 intake 698건은 조사 후보이며 화면 제품 30종에 자동 병합하지 않는다. 새 자료는 전체 SKU·지역·리비전·원문·상업성을 확인한 뒤 원본과 분리해 검토한다. 검색지수·글 수를 판매량/추천 점수로 사용하지 않는다.

사용자에게 남은 검토는 실제 디자인 사용감, 제품 이미지 권리와 수급, 원본 사람 검토, 댓글 운영 범위, 공개 도메인/배포, 광고·제휴 계정이다. 그 검토를 임의로 대신하지 않는다. 다음 개발은 검토 결과에 따른 좁은 수정과 확인된 제품 자료 추가다.

- 두 생성기 `--check` 통과, 자동 검사 워크플로에 추가.
- `npm run test:e2e -- --workers=2`: 로컬 118개 통과(기존 작업 트리 92 + 신규 26). 신규 13개 시나리오를 데스크톱/모바일 각각 실행했다. GitHub의 기존 커밋 테스트 수는 사용자의 미커밋 테스트 14개가 없어 로컬 수와 다르다. 해당 사용자 변경은 이번 커밋에 포함하지 않는다.
- 신규 검증: 검색·빈 결과·미확인 필터·입력별 주사율·2~3개 비교·지역/조건별 차이·출처·키보드·초점·axe·모바일 넘침·정적 문서·로컬 반응 저장/취소/오류·XSS/위험 URL·잘못된 데이터 envelope 차단.

## 남은 제한

제품 사양·한국 SKU·실물 호환성의 승인과 기능 테스트 통과는 다르다. 제품 사진 권리 확인 전 일반 일러스트를 사용한다. 구조화 사양의 일부 내부 키와 원문 조건은 영어로 남아 있다. 차이점 필터는 문서 위치·지역도 보수적으로 비교하므로 값이 같아도 조건 표기가 다르면 남는다. 우열 점수가 아니다.

브라우저는 최상위 데이터 상태를 검사하며 개별 제품 구조 검증은 Python 생성 단계와 CI에서 수행한다. 생성 파일을 수동으로 훼손하면 일부 형태는 친절한 오류 대신 JS 오류가 날 수 있다. 파생 파일 직접 편집은 금지다. 제품별 문서는 로컬 noindex이며 공개 SEO/GEO 효과나 검색 등록은 검증하지 않았다.
