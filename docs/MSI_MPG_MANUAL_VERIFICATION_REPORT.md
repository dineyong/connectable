# MSI MPG 321URX QD-OLED 설명서 후속 검토

2026-10-11 · `codex/monitor-purpose-design` · 기준 `47f0cb8`.

## 공식 근거와 반영 범위

[공식 모델 지원 페이지](https://www.msi.com/Monitor/MPG-321URX-QD-OLED/support#manual)의 Manual & Document 공개 메뉴에서 [한국어 설명서](https://download.msi.com/archive/mnu_exe/monitor/MPG271QRX_321URX_QD-OLEDv1.1_Korean.pdf) 연결을 직접 확인했다. 표지의 MPG 321URX(3DD2)가 조사 대상이며 공용 문서의 271QRX와 구분했다. V1.1, 2024/11 문서다.

| 확인 항목 | 위치 | 반영 |
|---|---|---|
| PIP/PBP 지원 | 인쇄17쪽 | boolean fact 2개 추가 |
| HDR 입력 시 PIP/PBP 설정 비활성 | 12쪽 | 조건 메모 |
| PIP/PBP 사용 시 Adaptive-Sync·Optix Scope·HDMI CEC 꺼짐, DisplayHDR 사용 불가 | 17쪽 | 조건 메모 |
| 한국 SKU·국내 보증·소비전력 | 이번 근거로 확정 불가 | 미확인 유지 |

입력별 동시 해상도·주사율 전체는 확인하지 못했다. 따라서 `per_input_simultaneous_conditions` 결측을 유지한다. 한국어 설명서 제공은 한국 판매 SKU 동일성의 증거가 아니다. 기존 240Hz를 공용 문서의 다른 모델 값으로 변경하지 않았다.

정확한 제조사·제품 ID·표시 모델·PDF URL 조합만 기존 등록표에 추가했다. 다운로드 도메인 전체 허용은 하지 않는다. 이 검사는 실시간 리다이렉트 감시 또는 국내 유통 SKU 승인이 아니다.

## 변경과 보존

- 공식 원본에 출처1개, 사실2개, 조건·적용 범위 메모 추가. 후속 확인으로 오래된 결측 설명 문장만 갱신.
- intake의 해당 원본 해시만 갱신. 파생 표시 데이터·정적 제품 문서·정보 목록 재생성.
- 다른29종 제품과 기존26개 사실 보존. MAG 등 기존 공식 충돌을 해소된 것으로 처리하지 않음.
- UI 코드·corpus·catalog·기존 사용자 변경은 작업 범위에서 제외. main 병합·공개 배포 없음.

## 검증

등록 전 신규2개 테스트 실패를 확인했다(미등록 출처 거부, PIP/PBP fact 부재). 등록 후 정확한 링크는 통과하고 다른 문서·버전·호스트·query는 거부한다. 조건 메모, 기존 주사율, 호환성 사용 불가 및 남은 결측 보존도 검사한다.

실행 결과는 아래에 기록한다. 최종 커밋은 본 보고서를 포함한 커밋이며 CI 결과는 push 후 완료 응답에서 제공한다.

## 남은 위험과 다음 단계

국내 판매 SKU·보증, 소비전력, 동시 입력별 제한은 추가 공식 근거가 필요하다. 모든 모델의 한국 SKU 조사가 끝난 상태는 아니다. 사용자가 추측으로 값을 선택할 필요는 없으며 현재 추가 결정 사항은 없다. 기존 충돌은 제조사 정정·리비전별 설명 전까지 유지한다.
