# 모니터 사양 비교 v3 진행 계획

기준일: 2026-10-10. [제품 방향 v3](PRODUCT_DIRECTION_V3.md)가 우선 기준이다.

## 진행바

단계 완료 수 기준 **3/6 완료**다. 각 단계의 작업량이 같다는 뜻이나 사이트 구현 50%라는 뜻은 아니다. 기존 연구/목업 완료를 새 사이트 완료로 합산하지 않는다.

`■■■□□□` 방향 확정 → 비교 데이터 → 새 화면 → 가벼운 참여 → 수익화 준비 → 운영 검증

| 단계 | 상태 | 산출물·통과 조건 |
|---|---|---|
| 1. 목표·목업 방향 확정 | 완료 | 사용자 승인 방향, 범위 문서, 이미지 시안, 계획 |
| 2. 비교 데이터 계약 | 로컬 기준 완료 | 조사 30종·637 facts 원본 보존, 보수적 필터·출처 매핑, 미확인 유지 |
| 3. 탐색·상세·비교 화면 | 로컬 구현 완료 | 승인 시안 구현, 검색·필터·2~3개 비교·차이점 강조, 데스크톱/모바일 회귀 |
| 4. 도움 반응·짧은 댓글 | 일부 구현 | 브라우저 내 도움 반응만 구현. 댓글 저장/운영 미구현. 저장·중복/스팸·검토·신고/삭제 설계, 실제/시연 구분, 접근성·입력 안전 검증 |
| 5. 가이드·판매처·광고 준비 | 일부 구현 | 짧은 가이드 연결, 판매처/광고 미활성. 콘텐츠 연결·정확한 SKU 링크·제휴 고지·광고 위치, 활성화 전 검토 |
| 6. 운영 품질·공개 후보 검토 | 로컬 검증 / 공개 대기 | 전체 테스트·CI·내부 링크·모바일·개인정보·댓글 운영·사양 표시 검토; main/공개는 별도 승인 |

실제 제품 확대·실시간 가격 수집·회원 기능은 이 순서의 선행 조건이 아니다. 판매처나 광고 계정을 확보하지 못하면 미연결 상태로 남기며 준비 완료와 실제 활성화를 구분한다.

## 현재 재사용할 자산

- 한국어 질문20건과 정식 v2 JSONL, 영어 예시5건, 원본 공식 catalog와 연구 pilot.
- 기존 사이트 데이터: 모니터6종·연구 기록38건·가이드3개. 제품 모델 연결과 SKU 동일성·사용자 수를 구분한다.
- 기존 화면: 두 제품 비교·일부 기능 필터·상세·가이드·검토 정보 표시. v3 화면 완성으로 집계하지 않는다.
- 최신 커밋 `8337e4b` 기준 Python423/브라우저72 및 CI 성공. 새 v3 화면의 검증 결과가 아니다.
- 보충 PD 근거·사람 검토 준비는 그대로 보존한다. 사람 검토 기록은 비어 있고 기존 공개 UNKNOWN은 유지한다.

## 최초 비교 데이터 계약 계획 — 아래 실행 기록으로 갱신

1. 기존 스키마·제품6종의 실제 필드를 조사해 크기·해상도·주사율·패널·포트·부가기능 매핑표를 만든다.
2. 공통 속성과 포트/조건별 속성을 구분한다. 최대/정격·지역 SKU·제품명 표기·미확인과 해당 없음의 의미를 정한다.
3. 숫자를 비교할 수 있는 항목, 조건부 표시할 항목, 숫자를 제시할 수 없는 항목을 구분한다. 필터는 미확인을 긍정 지원으로 포함하지 않는다.
4. 기존 원본은 바꾸지 않고 새 표시 계약/파생 방식을 설계한다. 부족한 값은 UNKNOWN으로 유지한다. 2026-10-10 추가 사용자 승인에 따라 별도 연구 영역의 모니터 확대 조사를 병행한다.
5. 실제 결측·단위 차이·포트 차이·서로 다른 SKU 사례로 회귀 테스트를 준비한 뒤 화면 구현으로 넘어간다.

## 진행 기록 방법

단계를 끝낼 때 이 표에 변경 커밋·실제 검증 결과·남은 항목을 기록한다. 전체 테스트 수만으로 서비스 정확도를 승인하지 않는다. 사용자 미커밋 작업과 별도 세션 변경을 무단 포함하거나 덮어쓰지 않는다. main 병합·공개 배포는 별도 지시 전 수행하지 않는다.
