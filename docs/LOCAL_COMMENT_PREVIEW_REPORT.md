# 로컬 댓글 초안 미리보기

## 구현 전 최소 설계

제품별 짧은 댓글 **초안 1개**를 현재 브라우저에만 저장한다. 공개 댓글·제품 사용 후기·공식 사양 근거가 아니며 작성자 이름·계정·집계·별점·샘플 문구를 만들지 않는다. 상세 화면에서 작성·저장·삭제할 수 있고, 저장 전에는 입력란에만 존재한다. 서버 요청은 하지 않는다.

최대 300자(유니코드 코드 포인트), 최대 30개 제품을 허용한다. 버전이 있는 단일 localStorage 키에 제한된 구조만 저장한다. 손상되었거나 지원하지 않는 구조는 임의 복구·덮어쓰기하지 않고 쓰기를 중단한다. 저장 실패 시 성공 메시지나 저장된 내용으로 바꾸지 않는다. 저장 항목은 textContent로 렌더링한다.

개인정보 입력을 요구하지 않으며 입력란에 개인정보를 쓰지 말라는 안내를 표시한다. 내용은 암호화되지 않는다. 같은 브라우저를 쓰는 사람이 읽을 수 있고 사이트 데이터 삭제 시 사라지며 다른 기기에 동기화되지 않는다. 자동 개인정보 탐지나 공개 검토를 수행했다는 주장은 하지 않는다.

공개 댓글 전환은 별도 승인 대상이다. 서버 저장·권한·삭제 요청·스팸 제한·신고·검토·개인정보 보관/삭제 정책을 설계해야 한다. 로컬 초안을 자동 게시하거나 공식 근거로 변환하지 않는다.

## 통합 계약

`window.ConnectableLocalComments.mount(container, productId)`를 상세 모달의 새 빈 컨테이너에 호출한다. `monitor-local-comments.js`와 `monitor-local-comments.css`를 로드한다. 기존 도움됐어요 반응은 변경하지 않는다. 저장 키는 `connectable-v3-comment-drafts`다.

## 검증

댓글 초안 테스트 6개를 데스크톱·모바일에서 실행하여 12개 통과. 저장·제품 분리·삭제·문자열 이스케이프·길이·손상·용량·저장 오류·접근 금지·요청 없음 검사 포함. 통합 브라우저 166개도 통과했으며 최종 기록은 LOCAL_MVP_SESSION_PROGRESS.md를 따른다.
