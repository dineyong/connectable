# 미확인 공식 사양 후속 조사

확인일: 2026-10-09. 기준: `a37fbfa`(코드 후보 `f391080` 포함).
작업 브랜치: `codex/official-gap-followup`.

[사람 검토 자료](HUMAN_CONTENT_REVIEW_PACKET.md)의 우선 미확인 항목 3개를 공식 공개 페이지로 추가 확인했다. 검색 결과 요약은 사실 근거로 사용하지 않고 열린 원문·브라우저 표시만 사용했다. 이번 산출물은 조사 보고서와 필요한 이미지 구간 캡처이며 기존 fact·역사적 재확인 배치·화면·검토 ledger를 변경하지 않았다. 사람 승인이나 한국 SKU/호환성 승인은 수행하지 않았다.

## 결과 요약

| 대상 | 새로 직접 확인한 사항 | 여전히 미확인 | 적용 상태 |
|---|---|---|---|
| V32UE 숫자 해상도·Hz | 기존 공식 출시 본문에 4K UHD 표기 | width·height·refresh_hz의 명시된 숫자 근거 | 원본 UNKNOWN 유지 |
| 27ULD950 PD | 공식 상세 이미지의 PD 65W 및 연결기기 화면출력·동시충전 설명 | 전압·전류 profile, 세부 단자/동시 소비 조건, 실제 호스트 수전 | 새 근거 확보, 기존 부분 확인/공급 필터 보류 유지 |
| LG 한국 SKU/전력 | 국내 공식 27UP850 페이지와 27UP850.BKR 표기, 숫자 해상도·Hz·USB-C 단자 | 해외 27UP850-W와 동일성, 국내 대상 PD W, 기존 RATED qualifier의 독립 근거 | 별도 국내 모델 근거, 기존 해외 fact에 미적용 |

신규 공식 근거 확보는 데이터 적용 승인과 다르다. 일부 공백을 줄였지만 세 항목 모두 완전 해결됐다고 기록하지 않는다.

## 1. V32UE

원문: [주연테크 공식 출시 자료](https://www.jooyon.co.kr/bbs/board.php?bo_table=press&page=16&wr_id=227). 직접 본문을 읽었다. 본문 위치는 V32UE 출시 설명과 뒤이은 기능 문단이다. 4K UHD 명칭과 USB-C 충전 설명은 있으나 이번에 읽은 본문에는 픽셀 수치·주사율이 명시되어 있지 않다. 4K라는 이름을 숫자로 변환하거나 V32UE-E/다른 모델의 사양을 대신 연결하지 않았다.

공식 본문에 연결된 Jooyonshop은 도구 timeout으로 상세 자료를 확보하지 못했다. [현재 주연테크 홈](https://www.jooyon.co.kr/)에서 연결된 회사 소개 사이트 `https://jooyontech.imweb.me/`는 HTTP403을 반환했다. 접근 제한을 우회하지 않았다. 허용 도메인 내 V32UE 설명서/숫자 사양 검색에서도 사용할 수 있는 공식 문서를 확보하지 못했다. 검색 실패는 문서가 존재하지 않는다는 뜻이 아니다.

원본 `jooyon-v32ue:site-1`의 숫자 UNKNOWN을 유지한다. 다음 필요한 근거는 정확한 V32UE 모델을 표시하고 픽셀·Hz를 명시한 공식 설명서 또는 제조사 답변이다. 제조사에 메시지를 보내거나 연락하지 않았다.

## 2. 27ULD950 공식 이미지

원문: [크로스오버 제품 페이지](https://www.crosslcd.co.kr/shop/item.php?it_id=1716533757). 텍스트 요약은 USB PD 지원만 확인되지만, 상품 상세설명의 두 번째 이미지에 추가 설명이 있다.

- 원본 상세 이미지: [공식 이미지](https://www.crosslcd.co.kr/data/editor/2411/047dd0567fcc29d7226521dd0b0f9f78_1732598597_5708.jpg).
- 확인 위치: 이미지 앞부분의 편의 특별기능 표, PD 65W 항목. 연결 기기의 화면 출력과 충전을 함께 제공한다는 설명을 시각적으로 읽었다.
- 확인 방법: 웹 도구의 해당 이미지 열기는 약16MB 크기 제한으로 실패했다. 공개 제품 페이지가 일반 브라우저에서는 정상 표시되어, 인앱 브라우저에서 읽기·스크롤로 해당 부분만 확인했다. 로그인·CAPTCHA·웹사이트 접근 차단 우회는 없었다. 전체 이미지를 내려받아 저장하지 않았다.
- 증거: [필요 문구 구간 캡처](evidence/crossover-27uld950-pd65-followup.jpg). 공식 페이지 이미지의 작은 발췌이며 새로운 제품 사진/사용자 후기가 아니다.

![크로스오버 공식 PD 65W 설명 발췌](evidence/crossover-27uld950-pd65-followup.jpg)

이번에는 상품명 PD65만이 아니라 별도 PD 65W 기능 설명을 확인했다. 후속 데이터 후보는 모델 범위의 제조사 표기 65W 및 연결기기 충전 기능이다. 최대/정격 qualifier, 전압·전류 profile이나 특정 Mac의 실제 충전 전력으로 확장하지 않는다. 해당 표의 USB-C 연결 설명은 별도 칸이며, 이것만으로 세부 포트/동시 소비 조건까지 확정하지 않는다.

이미지 하단 사양표의 전원 공급 항목과 소비전력 항목도 보았지만 이는 USB-PD 공급 전력과 별개다. 어댑터 전원 숫자를 PD W로 대체하지 않는다. 관련 전력 표기의 적용 범위는 제조사 확인이 필요하며 임의 산술 보정하지 않는다.

기존 `crossover-27uld950:site-2` 또는 역사적 부분 확인 배치를 조용히 승격하지 않았다. 다음 적용 단계에서는 새로운 공식 근거 배치를 만들고 그에 대한 별도 참조·검증을 설계한 뒤 사람 검토해야 한다. 상세 이미지 경로는 현재 공식 URL 자동 승인 route에 포함되어 있지 않으며 이번에 경로 정책을 완화하지 않았다. 공급 기능 필터의 기존 제외도 유지한다.

## 3. LG 한국·해외 구분

### 말레이시아 원본 재확인

[기존 LG MY 제품 페이지](https://www.lg.com/my/monitors/ultrafine-uhd-4k-5k/27up850-w/)는 이번에 직접 열렸다. All Spec → INPUT/OUTPUT의 USB-C (Power Delivery) 항목은 96W를 명시한다. 하지만 그 항목 자체는 정격 RATED 또는 최대 UP_TO qualifier를 명시하지 않는다. 이 재확인으로 기존 typed RATED를 독립적으로 승인한 것은 아니다. MY 수치를 한국 모델에 적용하지 않았다.

기존 [별도 LV 검토 배치](../data/official/spec_manual_review_2026-10-09.json)의 UP_TO96W와 원본 RATED96W는 이번에 수정하거나 합치지 않았다. LV 자료는 이번 조사에서 새로 읽었다고 기록하지 않는다.

### 국내 공식 모델 발견 및 직접 확인

[LG전자 국내 사업자몰 27UP850](https://www.lge.co.kr/business/monitors/27up850)을 열고 브라우저에서 **제품 스펙 더 보기**를 펼쳤다. 페이지 표제/모델 버튼은 27UP850이며 메인 이미지의 접근성 설명에 27UP850.BKR가 명시된다. 단종 및 상세 정보 기준일 2024-10-25도 표시된다. 이 정보 기준일은 이번 확인일과 다르며 새 출시 날짜로 저장하지 않는다.

화면 스펙은 해상도3840×2160, 입력 신호는 주사율60Hz와 USB-C 포함 연결 단자를 명시한다. 그러나 읽은 국내 스펙에는 USB-PD 공급 W가 없었다. 전기적 특성의 모니터 소비전력과 정격 입력 전압을 호스트 충전 전력이나 PD profile로 해석하지 않는다.

해외 원본의 표시 모델은 27UP850-W다. 국내 27UP850/27UP850.BKR와의 동일성은 명칭 유사성만으로 승인하지 않는다. 같은 제조사·같은 숫자 해상도여도 SKU 바인딩을 확정할 수 없다.

[국내 27UP850K 페이지](https://www.lge.co.kr/product/monitors/27up850k)도 직접 열어 확인했으며 USB-C 충전 최대90W를 명시한다. 이는 별도 K 모델의 근거이고 기존 27UP850-W 또는 국내27UP850에 연결하지 않았다. 96W와90W를 동일 제품의 충돌로 자동 판정하지 않는다. 국내 공식 검색에서 N/K/접미사 없는 모델이 구분되는 점은 모델명 생략·자동 별칭 승격을 피해야 하는 이유다. 새 제품 catalog를 추가하지 않았다.

### URL 정책

현재 `official_url_status`는 LG에 www.lg.com의 제한된 경로만 인정한다. `https://www.lge.co.kr/business/monitors/27up850`는 **UNKNOWN**을 반환함을 실제 확인했다. 국내 공식 페이지를 발견했다는 이유로 allowlist를 이번에 확장하지 않았다. 향후 도메인/제품·사업자몰 route와 redirect 입력 계약을 별도 검토해야 한다. 모델 동일성 검사는 도메인 정책 승인과도 별개다.

한국 사양 탐색 초기의 `https://www.lg.com/kr/monitors/27up850`는 도구에서 접근 불가, www.lg.com/kr는404였다. 이후 실제 국내 공식 lge.co.kr 페이지를 발견했다. 초기 URL 실패를 국내 제품 부재의 증거로 쓰지 않았다.

## 산출물·검증

보고서와 공식 이미지의 최소 구간 캡처만 추가했다. 새로운 제조사 스키마·별칭·출처 정책·공개 승인·UI 기능은 구현하지 않았다. 개인정보나 원문 전체를 저장하지 않았다. 원본 확인일도 덮어쓰지 않았다.

- `python3 scripts/build_site_content_v2.py --check`: 통과.
- `python3 web/derive-site-content.py --check`: 통과.
- `python3 -m scripts.content_review`: 통과, 실제 검토 ledger0건·공개 보류.
- 기존 파일·사용자 변경 hash 보존, fact hash 대조, 새 문서 내부 경로·비밀값/연락처 패턴·`git diff --check`: 통과.
- 전체 테스트는 이번 브랜치 GitHub CI에서 재실행한다. 완료 응답에 실제 결과와 링크를 기록한다. 직전 기준은 Python392/브라우저72이며 테스트 수를 추가하지 않았다.

main·원본 사양·후기·기존 목업·역사 배치·사용자 미커밋 문서는 변경하지 않았다. 사람 검토 체크박스/담당자/결과를 대신 작성하지 않았으며 공개 배포·광고·제휴·제조사 연락도 수행하지 않았다.

## 다음 적용의 최소 단위

1. 크로스오버 이미지 근거를 기존 부분 확인과 분리한 새 모델 범위 assertion으로 구조화하고, 이미지 출처 참조 및 확인 범위의 검증을 추가한다. 필터나 원본 변경은 그 검토 이후 판단한다.
2. 국내 LG 도메인·route 정책과 국내 표시 모델의 별도 식별 구조를 검토한다. -W/BKR/K/N을 자동 동치로 두지 않는다. 한국 SKU 사양으로96W를 노출하지 않는다.
3. V32UE 명시 숫자 공식 문서 확보와 LG qualifier 의미 확인이 필요하다. 확보 전 UNKNOWN/검토 대기를 유지한다.

이 단계는 조사 근거 확보이며 통합 승인과 운영 콘텐츠 확정은 계속 별도 단계다.
