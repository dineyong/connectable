## 완료 범위

- [30종 제품 정보·이미지 목록](PRODUCT_INFORMATION_IMAGE_INVENTORY.md): 제품 ID, 모델, 문서 지역, 공식 출처, 검색 핵심값 결측, 기록된 결측 수, 이미지 상태. 생성 스크립트와 원본 해시로 오래된 목록을 검출한다.
- 검색 핵심 사양 결측 우선순위: ASUS XG27AQDMG 크기·주사율, PG32UCDM 주사율·패널. USB-C 영상 미확인과 미지원도 계속 구분한다.
- 30종 모두 문서 모델은 식별됐지만 한국 SKU 동일성이 미확인이다. 해외 문서값을 한국 판매 사양으로 승격하지 않았다.
- 이미지 30종: CSS 형태 예시 유지. 제품 사진 원본 URL·권리자·상업 재사용 범위 확인이 필요하다. 기존 Dell/ASUS 이용 조건 검토 문서는 보존했다. 이번에는 공식 웹 원문·이용 조건을 재조사하거나 사진을 확보한 것이 아니다.
- 사용자 결정 반영: 첫 화면 참여 기능은 👍 도움이 됐어요 반응. 댓글 입력은 상세 화면에서 제외한다. 기존 댓글 모듈과 로컬 저장값을 삭제하지 않는다. 댓글 회귀 테스트는 테스트 내부에서만 모듈을 장착하여 계속 수행한다.
- 반응은 브라우저 로컬 저장이며 총 사용자 수·구매 인증·제품 평가가 아니다. 공개 반응 서버는 아직 없다.

## 사용자가 확인할 부분만

1. 제품 이미지: 직접 촬영 또는 상업 사용이 허용된 공급 자료가 있으면 원본과 허용 근거를 제공. 없으면 형태 예시로 진행하며 임의 다운로드하지 않는다.
2. 출시 전 공개 범위: 해외 공식 문서·한국 SKU 미확인 표시를 유지한 제품까지 공개할지, 한국 모델 확인 제품부터 공개할지 결정.
3. 나중에: 뉴스 API 계정, 도메인·호스팅·쿠팡 사이트 등록과 공개 시점. 키는 채팅/저장소에 남기지 않는다.

댓글 후순위·이모지 우선은 이미 결정됐으므로 다시 승인을 요청할 항목이 아니다. 지금 당장 추가 답변은 필요하지 않다.

## 이어서 할 수 있는 작업

1. 핵심 결측 2종의 공식 문서 재확인과 입력별 조건 정리.
2. 한국 판매 SKU 공식 근거 대조 및 공개 후보 목록 작성.
3. 허용된 이미지가 확보되면 제품 일치·크기·대체 텍스트 검증 후 적용.
4. 공개 이모지 집계는 별도 저장소·중복/남용 방지·삭제 기준을 갖춘 뒤 구현. 현재 로컬 반응을 전체 집계로 표시하지 않는다.
