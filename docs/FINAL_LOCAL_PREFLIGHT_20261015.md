## 재현 후 수정한 문제

수정 전 신규 회귀 테스트 4개 모두 실패했다. 잘못된 입력은 원본이 아닌 TemporaryDirectory 복사본에만 넣었다.

1. 보강 페이지 robots를 index로 변경하고 noindex 주석만 남겨도 승인되는 문제: 모든 포함 HTML의 실제 metadata 검사로 차단.
2. 보강 페이지에 canonical을 추가해도 승인되는 문제: 공개 URL 보류 계약으로 차단.
3. 보강 페이지의 없는 CSS가 승인되는 문제: 모든 포함 페이지의 로컬 경로 검사로 차단.
4. 손상된 monitor-v3-data.js가 승인되는 문제: 모니터·후기·저장 뉴스·제품 발표의 파생 JS 4종을 검증된 기존 원본에서 메모리 재생성한 기대값과 비교. 복사 전후 모두 검사.

루트 index는 현재 화면의 의도적 별칭이므로 별도 검증해 중복 title 예외를 좁혔다. 검사 기준을 완화하지 않았다. 추가 회귀는 4종 파생 JS의 원문 일치와 잘못된 입력 시 출력 미생성을 확인한다. 독립 세션의 10개 통과 뒤 통합 세션에 자산별 검사를 하나 더 추가했다.

## 최종 판단과 남은 일

**현재 로컬 후보에서 출시를 막는 추가 기능 오류는 발견하지 않았다.** 이는 결함이 없다는 보증, 외부 보안 감사, 제품 실측, SKU 승인 또는 뉴스·사진 사용권의 전면 확인이 아니다. 알려진 패키지 경계 4건은 수정 후 재현 차단을 확인했다.

다음은 도메인·호스팅 조건 확인과 접근 제한된 실제 후보, 호스팅 헤더·404·정적 HTML·최종 공개 승인이다. 원격 URL·정적 canonical/sitemap·검색 도구는 그 이후다. 지금 승인되지 않은 공개 배포/main 병합/광고/API/공개 반응 집계를 추가하지 않는다.

뉴스는 모니터 공식 발표 소수를 직접 검토하는 흐름을 우선하며 새 데이터 수집·시간표·계정 등록은 이번에 하지 않았다. 미확인 사양 276개를 전부 채우거나 사진·댓글을 만드는 일을 첫 출시 조건으로 삼지 않는다. LS34C650UEEXXY 후기는 새 정확 근거가 올 때까지 보류한다. 관련 원본 30종과 후기 29종35링크를 유지한다.
