# 구매 가이드·모니터 후기 사이트 10개 벤치마크

확인일: 2026-10-08. 현재 제품 방향은 [구매 가이드 + 연결 후기](PRODUCT_DIRECTION_V2.md)다. 이 문서는 조사와 적용 제안이며 기능 채택·구현 완료·수익 검증을 뜻하지 않는다. 기존 데이터·화면·스키마는 변경하지 않았다.

## 방법과 한계

10개 서로 다른 서비스의 공개 원문을 web 도구로 직접 열었다. 검색 요약만으로 기능을 확정하지 않았다. RTINGS, 다나와, TFTCentral, DisplayNinja, 퀘이사존, PC Monitors, PRAD, KitGuru, TechSpot은 실제 데스크톱 브라우저의 첫 화면도 확인했다. Reddit은 공개 페이지 본문에서 글 분류·규칙을 확인했지만 브라우저에서는 사람 확인 화면이 나와 중단했다. Reddit의 현재 시각 배치는 미검증이다. 로그인·게시·구매·CAPTCHA 해결·유료 영역 접근·차단 회피를 하지 않았다.

홈·일부 비교/목록/게시판까지 확인했으며 모든 상호작용과 모바일을 테스트한 결과는 아니다. 시각 관찰과 기능 존재 확인, Connectable 적용 판단을 구분한다. 도구 본문과 실시간 브라우저의 기사·숫자는 시점 차이가 있으므로 이용자 수·제품 수·트래픽·수익 추정에 사용하지 않는다. 외부 글·사진·점수·디자인 자산을 복제하지 않고 구조만 참고한다. 개인 닉네임·댓글 본문은 저장하지 않았다.

## 10개 분석

### 1. RTINGS — 제품 비교와 근거 구조

근거: [모니터 홈](https://www.rtings.com/monitor), [비교 도구](https://www.rtings.com/monitor/tools/compare).

확인: 용도별 구매 가이드, 제품 리뷰, 비교 도구, 시험 방식과 업데이트 정보가 연결된다. 비교 페이지에 제품 두 개를 나란히 놓고 결론·입력·USB·macOS 항목과 구매처를 나눈다. 일부 결과는 회원 영역이며 공개 추출의 0.0·Locked를 실제 평가값으로 읽으면 안 된다. 홈은 강한 빨간 메뉴와 큰 히어로·콘텐츠 섹션이다.

적용 제안: 두 제품 비교표에서 USB-C 영상, 공식 PD 제공 최대, 포트별 해상도/Hz, 높이 조절, KVM, 스피커, 같은 컴퓨터 후기 여부를 비교한다. 확인일과 출처를 연결한다. 평가 실험이 없는 Connectable이 종합 실측 점수를 흉내 내지 않는다. 수익 고지는 회원·구매 링크 수수료 등으로 명시돼 있지만 우리에게 같은 성과가 난다는 증거는 아니다.

### 2. DisplayNinja — 부가기능으로 찾는 목록

근거: [홈](https://www.displayninja.com/), [USB-C 모니터 목록](https://www.displayninja.com/usb-c-monitor-list/).

확인: USB-C, KVM, 데이지체인, Ethernet 등 기능별 목록과 용도별 구매 가이드를 구분한다. 홈은 큰 기사 이미지와 최신 글 사이드 목록이다.

적용 제안: ‘케이블 하나로 충전’, ‘키보드·마우스 공유’, ‘스피커 내장’, ‘높이 조절’처럼 생활 언어의 필터를 제공하고 작은 도움말에서 규격을 설명한다. 기능 존재는 모델별 공식 자료로 채운다. USB-C 단자만으로 충전·영상 지원을 추정하지 않는다. 전문 용어 메뉴 수를 그대로 늘리면 초보자의 탐색이 어려워진다.

### 3. TFTCentral — 구매 뒤에도 읽는 설정 가이드

근거: [홈](https://tftcentral.co.uk/).

확인: 리뷰·기사·추천·설정 가이드·교정 설정 자료·출시 추적을 메뉴로 구분한다. 큰 대표 콘텐츠와 여러 작은 타일, 날짜, 별도 광고 영역이 보인다. 광고·후원·회원 지원 관련 메뉴가 있으나 실제 수익은 조사하지 않았다.

적용 제안: 제품 상세에서 관련 설정·연결 문제 가이드로 이동한다. ‘구매 전 확인’과 ‘구매 후 사용’을 구분하면 재방문 이유가 생긴다는 것은 우리 설계 가설이다. 다른 모니터의 ICC/설정값을 그대로 적용하지 않고 OS·모델 범위를 표시한다. 슬라이더와 큰 광고로 첫 콘텐츠가 밀리는 배치는 복제하지 않는다.

### 4. 다나와 — 검색에서 콘텐츠와 쇼핑으로 이동

근거: [홈](https://www.danawa.com/).

확인: 큰 검색창, 카테고리, 최근·관심 진입점, 뉴스룸·쇼핑노트·커뮤니티·기획전·판매 서비스 링크가 한 화면에 연결된다. 실제 화면에는 광고 팝업이 있어 일부 배치를 가렸다. 이번에는 개별 상품 가격비교 전체 동작을 검증하지 않았다.

적용 제안: 모니터 모델 검색과 최근 본 제품을 가벼운 탐색 보조로 둔다. 상세에서 정보→후기→구매처 흐름을 유지한다. 전 쇼핑 카테고리·최저가 추적·팝업은 도입하지 않는다. 최근 본 기능을 추가하면 저장 범위와 삭제 방법을 정하고, 가격 표시를 넣는 경우 최신 출처·시각이 먼저 필요하다.

### 5. 퀘이사존 — 후기와 질문의 분리

근거: [홈](https://quasarzone.com/), [모니터 게시판](https://quasarzone.com/bbs/qf_dp).

확인: 공식 리뷰·벤치마크, 사용자 리뷰/체험기, 팁, 질문/토론, 데스크셋업, 핫딜을 분류한다. 어두운 배경과 카테고리 탭, 검색, 목록형 콘텐츠가 특징이다.

적용 제안: 카드 유형을 ‘사용 후기 / 연결 문제 / 구매 전 질문 / 해결 후기’로 구분하고 같은 컴퓨터·모니터 필터를 제공한다. 장비·OS·연결 방식·실제 수행 결과를 상세 상단에 둔다. 질문 답변과 작성자의 성공을 분리한다. 많은 게시판과 이벤트·포인트는 초기 운영 부담이 커 후순위다. 체험기는 관계 고지를 보존한다.

### 6. Reddit r/Monitors — 경험 피드와 운영 규칙

근거: [공개 모니터 커뮤니티](https://www.reddit.com/r/Monitors/).

확인: 공개 본문에 Discussion·Photo·News 등의 글 분류, 커뮤니티 하이라이트, 주제·내용 품질·홍보 승인 규칙이 있다. 브라우저의 사람 확인 화면 때문에 시각 UI는 직접 검증하지 못했다.

적용 제안: 짧은 경험 카드와 내용 유형 태그, 필수 구성 정보가 있는 작성 양식, 이해관계 표시를 검토한다. 추천·댓글 수는 사실성 점수가 아니며 원문 댓글을 호환 승인으로 쓰지 않는다. 자유 게시판을 지금 추가하는 결정은 아니다. 회원·댓글·신고 운영은 후속 단계다.

### 7. PC Monitors — 적은 메뉴와 읽기 쉬운 제품 요약

근거: [홈](https://pcmonitors.info/), [추천 진입](https://pcmonitors.info/recommendations/).

확인: 추천·리뷰·설명 글·토론 포럼을 구분한다. 목록은 큰 제품 이미지 옆 제목·요약·날짜·더 읽기 형태이며 추천 진입은 용도별 설명으로 이어진다.

적용 제안: 메뉴는 ‘모니터 찾기 / 사용 후기 / 구매·연결 가이드’로 유지한다. 카드에는 모델명과 함께 핵심 차이를 짧게 설명한다. 쉬운 설명을 접한 뒤 상세 사양으로 들어가게 한다. 긴 모델명과 요약이 모바일에서 잘리는지는 실제 구현에서 검증해야 한다.

### 8. PRAD — 사양·비교·후기를 서로 연결

근거: [홈](https://www.prad.de/), [모니터 비교](https://www.prad.de/test-kaufberatung/produktvergleich/monitor/).

확인: 모니터 검색·사양·구매 가이드·리뷰·포럼을 연결하고, 비교 페이지는 최대 네 제품의 선택·추가·제거·순서 이동·공유 방법을 설명한다. 홈은 이미지 위 제목·날짜를 얹은 격자형 카드다. 광고성 콘텐츠는 Anzeige 표기가 보인다. 실제 비교 저장/게시 제출은 하지 않았다.

적용 제안: Connectable은 우선 두 제품 비교와 공유 가능한 링크부터 검토한다. 상세의 기능·사용 경험·주의점으로 이동하는 탭 또는 앵커를 둔다. 차이만 보기 기능은 우리 추가 제안이며 이번 조사에서 PRAD의 제공 기능으로 확인한 것은 아니다. 사양표만 늘려 실제 맥북 연결 결과를 가리지 않는다.

### 9. KitGuru — 신제품과 리뷰의 콘텐츠 분류

근거: [모니터 카테고리](https://www.kitguru.net/category/peripherals/monitors/).

확인: 모니터 기사 목록에서 제목·이미지·날짜·요약·더 읽기를 제공하고 News/Featured Tech Reviews/Reviews 등의 구분이 보인다. 실제 화면에 상단과 옆 광고가 배치돼 있다.

적용 제안: 편집 가이드·제조사 신제품 소식·사용자 후기를 구분하고 날짜를 노출한다. 광고는 콘텐츠 블록 사이에 분리해 예약 공간을 확보한다. 뉴스 소개를 실사용 후기처럼 표시하거나 상단·옆 광고를 모두 복제하지 않는다. 광고가 많아도 수익이 높다는 결론은 내릴 수 없다.

### 10. TechSpot — 용도별 목차와 구매 가이드

근거: [모니터 구매 가이드](https://www.techspot.com/bestof/monitors-25/).

확인: 2025-08-14 게시 가이드이며 생산성·창작·게임·휴대·예산 항목으로 나눈 목차, 제품별 설명·대안, 구매 링크와 수수료 고지가 보인다. 큰 제목·대표 작업 공간 이미지·기사 목차를 사용한다. 2026 최신 추천 목록으로 취급하지 않는다.

적용 제안: 긴 가이드 상단에 ‘누구에게 필요한가 / 비교할 항목 / 아쉬운 점 / 관련 후기’ 목차와 요약을 둔다. 국내 가격·재고를 확보하기 전 해외 가격을 그대로 쓰지 않는다. 용도별 순위나 종합 점수는 평가 근거가 생긴 뒤 검토한다.

현재 화면의 가장 큰 결핍은 카드 수가 아니라 모니터에 직접 연결된 사용 경험이다. 기존 모니터3개는 관련 후기0건이므로 기능 비교만 먼저 할 수 있다. 예정된 후기 기반 후보3~5개 구축을 유지하고, 사양 데이터가 없는 필터·가격·별점·성공률은 먼저 꾸미지 않는다.

## 추천 화면 구성

홈: 간결한 첫 문구 → 관심 기능 선택 → 모니터 카드 → 실제 연결 경험 → 질문형 가이드. 긴 장식 히어로가 탐색 시작을 지나치게 미루지 않게 한다.

모니터 카드: 제품 이미지(권리 확인 전 개념도)·정확한 모델·핵심 기능3개·동일 모델 후기 존재 여부·‘자세히 보기’·‘비교 담기’. 외부 구매 링크는 상세 검토 뒤 별도 버튼으로 둔다.

제품 상세: 요약 → 공식 부가기능 → 사용자의 구성별 경험 → 좋은 점/불편한 점 → 어떤 케이블·설정으로 사용했는지 → 관련 가이드 → 출처와 확인일 → 구매처. 신뢰 정보는 숨기지 않되 메인 문구의 UNKNOWN은 ‘아직 확인되지 않음’, ID는 접힌 근거 영역으로 옮기는 방안을 권한다. 단일 후기의 경험을 일반적 장단점으로 확정하지 않는다.

후기 카드: 컴퓨터·모니터 표시명 / 케이블·독 요약 / 화면·충전·복귀를 각각 표시 / 사용 후기·질문·해결 후기 태그. 장비 사진은 권리 확인 시만 사용하고 외부 사진이나 생성 이미지로 실제 후기 증거를 만들지 않는다.

모바일 제안: 필터는 접고 선택 조건을 칩으로 남긴다. 비교는 두 열의 가로 이동과 고정 항목명 또는 항목별 두 값으로 제공한다. 상세 내 위치 이동은 짧은 탭으로 한다. 이것은 이번에 경쟁 사이트 모바일을 검증한 결과가 아니라 후속 구현 제안이다.

## 트래픽과 수익화 판단

용도/기능별 목록·질문형 가이드에서 정확한 제품 상세와 후기로 이동하고, 구매처는 마지막에 연결하는 구조를 권한다. 이는 수익과 체류 개선을 기대하는 가설이며 실제 유입·전환 측정은 없다. RTINGS/TechSpot의 수수료 고지와 TFTCentral/KitGuru의 광고 분리에서 투명한 표시 구조를 참고할 수 있다. 관찰한 광고가 애드센스라는 확인은 하지 않았고 각 사이트 매출도 모른다.

Connectable은 초기 실제 계정 승인·제품 식별·최신 정책 확인 후 제휴 링크를 연결한다. 광고는 비교 버튼·상세 닫기·메뉴와 떨어진 콘텐츠 구간에 제한한다. 같은 모델이 아닌 구매상품 링크, 수수료 순 추천, 광고만 위한 빈 콘텐츠, 가짜 후기/평점, 첫 방문 전면 광고는 피한다. 계정 정책 준비는 [기존 계획](SITE_V2_QA_MONETIZATION_PLAN.md)에 따른다.

## 확인하지 못해 분석 건수에서 제외한 후보

DisplaySpecifications(시간 초과), PCPartPicker(403), ProductChart(403), 노써치(본문 오류), Wirecutter(본문 오류), 오늘의집(본문 오류), Tom’s Hardware(도구 접근 불가), TechPowerUp(시간 초과). 접근을 우회하거나 기능·시각 UI를 추정하지 않았다. 서비스가 폐쇄됐다는 뜻은 아니다. Reddit은 본문 확인이 됐으므로 기능 분석에 포함하되 브라우저 시각 검증 실패를 구분했다.

## 후속 작업

기존 후기 기반 모니터3~5개 후보 조사와 병행해 P0 상세 구조·후기 카드·공식 기능 필터를 먼저 구체화하고, 그다음 두 제품 비교를 구현하는 순서를 제안한다. 제품방향·원본자료·현재화면·공개승인 상태는 변경하지 않았고 commit/push/merge/배포도 하지 않았다. 문서 내부 경로·외부 출처10사이트·공개 접근 범위를 확인했다. 문서만 추가한 작업으로 기존 코드 테스트를 반복하지 않았다.
