# 테크 소식: 신제품과 사전예약 확장

2026-10-11 · `codex/monitor-purpose-design` · 공개 UNKNOWN 유지.

## 이번 반영

기존 삼성/Windows RSS 스냅샷을 보존하고 별도 [발표 원본](../data/news/product_announcements.json)에 본문 직접 확인 2건을 기록했다. [생성·검증기](../scripts/product_news.py)가 [파생 JS](../web/product-news-data.js)를 생성한다. 전체 unittest에서 원본/파생 일치도 검사한다. 원본 제품 사양 데이터나 비교 필터에는 연결하지 않는다.

- [BenQ 한국](https://www.benq.com/ko-kr/news/products/benq-launches-ex271qmzqmqp.html): 2026-09-20 게시일, EX271QMZ/EX271QM/EX271QP 출시 발표 본문 확인. 정확한 판매 개시 날짜는 별도로 명시하지 않고 null 유지.
- [Apple 대한민국](https://images.apple.com/kr/newsroom/2026/09/apple-unveils-iphone-duo/): 2026-09-09 보도자료, ‘가격 및 출시 일정’의 대한민국 포함 국가 목록에서 10월 16일 사전주문과 10월 23일 구매 가능일 확인. 원문의 날짜를 기록하며 현재 예약 상태·재고·판매처 혜택으로 확대하지 않는다. 정확한 시간은 이번 날짜 단위 구조에 저장하지 않는다.

두 자료는 웹 원문 열람으로 확인했다. 전문·이미지·개인정보는 저장하지 않았다. 공식 본문을 사실 중심으로 짧게 정리했으며 자동 요약/자동 승인으로 운영하지 않는다. 각 행은 확인일과 원문 위치, 공개 검토 대기 상태를 보존한다.

화면 상단에 ‘신제품 · 사전예약 체크’, 분류 선택, 발표일/확인일/발표된 일정/원문 링크를 추가했다. 기존 RSS 영역과 제목 기반 분류를 분리했다. ‘예약 중’·카운트다운·최저가·혜택 확정 표현은 생성하지 않는다.

## 삼성 뉴스룸 외의 수집 방법

| 방법 | 역할 | 이번 상태 |
| --- | --- | --- |
| 제조사 제품 발표 직접 확인 | RSS 없는 모니터 신제품과 국내 출시 안내 | BenQ/Apple 2건 반영 |
| [네이버 뉴스 검색 API](https://developers.naver.com/docs/serviceapi/search/news/news.md) | 국내 매체 기사 후보 발견, 날짜순 검색과 원문 링크 | 공식 문서 확인. 앱 등록·Client ID/Secret 필요, 미연동 |
| [Ars Technica RSS](https://arstechnica.com/rss-feeds/) 등 전문 매체 RSS | 독립 매체의 테크 기사 후보 | RSS 제공 확인. 상업 사이트 재사용 조건 확인 전 미수집 |
| 제조사 공식 판매 페이지·통신사 공지 | 한국 사전예약 기간, 판매처별 혜택·조건 대조 | 다음 조사 대상. 이번에 혜택/판매 상태를 추가하지 않음 |
| 커뮤니티 제보 | 놓친 출시 후보 발견 | 공식 발표/판매 조건의 증거로 자동 승격하지 않음 |

LG 글로벌 뉴스 목록 직접 열람은 이번 도구에서 오류로 끝나 추가하지 않았다. 검색 결과 요약만으로 행을 만들지 않았다. 네이버 API는 검색 후보 제공 수단이며 원문 복제 권리를 부여하는 것으로 간주하지 않는다. 외부 URL을 자동으로 따라가는 크롤러는 추가하지 않았다.

## 다음 권장 작업

1. 제조사별 모니터 발표를 소규모로 추가하되 한국 출시와 해외 발표 구분.
2. 네이버 검색 API를 서버측 후보 큐에 연결할 때 비밀값을 브라우저에 전달하지 않고 이용 조건 확인.
3. 사전예약은 공식 판매처의 시작·종료 시각/시간대, 확인 시각, 대상 모델·조건을 별도 검토한 뒤 상태 표시 설계.
4. 중복 발표 묶기와 검토 큐, 갱신 실패 표시를 마련한 뒤 정기 운영 여부 결정.

상시 갱신, 공개 배포, 광고·제휴, main 병합은 하지 않았다. 이번 직접 확인 자료는 고정된 발표 기록이며 실시간 뉴스 서비스 완료를 뜻하지 않는다.
