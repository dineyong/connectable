# 출시 후보 로컬 검수 · 2026-10-15

기준: `codex/monitor-purpose-design` · `bfc4127290bc52ec125656bbedbfa95475083514`. [제품 방향](PRODUCT_DIRECTION_V3.md), [공개 전 체크리스트](LOCAL_SITE_RELEASE_CHECKLIST.md), [최근 통합 결과](LOCAL_SITE_REMAINING_WORK_INTEGRATION_REPORT.md)에 따라 공개 배포·가격·광고·집계·호환성 승인을 제외했다.

## 실제 검수 방식

이미 실행돼 있어야 하는 `http://127.0.0.1:8875`에 접속했다. 최초 연결은 `ERR_CONNECTION_REFUSED`였으며 통합 세션이 로컬 서버를 복구한 뒤 실제 HTTP 200 응답에서 검수했다. 프로세스 종료 상태와 사이트 코드 결함을 혼동하지 않는다.

별도 Playwright Chromium 브라우저의 **새 격리 context**에서 1440×1000 데스크톱과 390×844 모바일을 검수했다. 사용자 브라우저의 비교·이모지·초안 저장값은 접근하지 않았다. 시연 반응은 같은 격리 context에서 다시 해제하고 context를 폐기했다. 전체 e2e 서버나 수집 타이머는 이 검수 세션에서 실행하지 않았다.

## 발견 사항 및 좁은 보강

1. **검색 레이블:** `monitor-purpose.css`가 `label[for=monitor-search]`를 `display:none` 처리해 입력 이름이 placeholder로 대체된다. 전체 axe 규칙은 `label-title-only` serious 1건을 두 화면 폭에서 재현했다. 이는 실행 오류나 데이터 오류는 아니지만 입력 후에도 검색 목적을 읽을 수 있는 명시적·지속적인 레이블이 필요하다.
2. **미리보기 안내 랜드마크:** `.preview-strip`이 header/main 밖에 있어 전체 axe `region` moderate 1건을 두 폭에서 재현했다. 안내의 문장·보류 상태를 유지하며 이름 있는 region으로 표현하는 최소 조정을 권한다.

[회귀 테스트](../tests/e2e/release-candidate.spec.js)는 visible label과 label-title-only 규칙, preview 안내의 이름 있는 landmark와 region 규칙·noindex를 검증한다. 테스트 개수만 늘리기 위해 기존 테스트를 복제하지 않았다.

## 수정 후 재검증

검색 label은 기존 `for` 연결을 유지한 채 짧은 `모니터 검색` 문구와 11px 표시로 복구했다. 기존 헤더·검색 기능·필터 계약을 바꾸지 않았다. 미리보기 strip에는 `role=region`과 이름 `로컬 미리보기 안내`만 추가했다.

수정 후 같은 standalone Playwright 동선을 다시 실행했다. **1440×1000·390×844 모두** 검색/빈 결과/비교/상세/반응/가이드/뉴스 동선 통과, pageerror 0. 첫 화면·비교 dialog·상세 dialog·구매 가이드·테크 소식·정적 목록의 **총 12회 전체 axe 검사 위반 0건**. 모든 해당 화면 document 가로 넘침 없음.

## 검증 범위와 남은 위험

- 오프라인 `python3 scripts/validate_local_site.py` 통과.
- 수정 전 첫 화면에서 위 2건이 발견됐고 수정 후 전체 axe 검사에서 위반 없음. 자동 검사가 수동 보조기기 사용·모든 대비/인지 사용성을 보장하지 않는다.
- 공식 원문을 재조사하거나 근거를 승격하지 않았다. 현재 문서 지역/SKU·충돌·공개 UNKNOWN 정책, LS34C650UEEXXY 보류를 유지한다.
- 실제 제품 이미지는 이번 검수에서 추가·다운로드하지 않았다. 별도 사용권 조사 결과를 따른다.
- 외부 URL 목적지의 상시 가용성, 미래 리다이렉트, 영상 내용 전체의 정확도는 로컬 검수 통과로 보증하지 않는다.
- 전체 Python·데스크톱/모바일 브라우저와 최종 CI 결과·변경 파일·보존 hash는 통합 세션 보고서에 실제 실행 후 기록한다.
- 도메인·호스팅·공개 승인·색인·광고·사진 허가·공개 참여 운영 결정은 실행하지 않았다. 현재 로컬 작업 범위에서 사용자에게 새 결정을 요청할 필요는 없다.
