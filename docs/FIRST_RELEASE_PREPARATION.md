# 첫 출시 준비 기준 · 2026-10-15

상태: 사용자가 공개 범위와 아래 준비 방향을 승인했다. **실제 공개·배포·색인·main 병합 승인은 아니다.** 도메인은 사용자가 결정한다. 현재 개발 브랜치 `codex/monitor-purpose-design`에서 로컬 준비를 진행한다.

## 후속 준비 결과

[최종 로컬 점검](FINAL_LOCAL_PREFLIGHT_20261015.md): 패키지 전체 HTML·파생 JS 검증을 보강하고 자료 안내·404 템플릿을 포함했다. 현재 출력은 57파일이며 초기 55파일 패키지는 이전 산출물이다. 도메인·실제 공개 보류는 유지한다.

## 확정된 방향

1. 해외 제조사 공식 문서 기준 제품도 공개 후보에 포함한다. 카드·상세·비교에 문서 지역, 한국 판매 SKU 미확인, 누락·충돌과 출처를 유지한다. 지역별 보증·SKU·실측 결과를 자동 동일시하지 않는다.
2. 첫 출시 핵심은 모니터 검색·필터·2~3개 사양 비교·공식 사양 상세·외부 후기 링크·구매 가이드다. 모든 결측을 채우거나 호환성 엔진을 승인할 필요는 없다.
3. 정적 사이트 중심으로 준비한다. 도메인·유료 호스팅 계약·월 지출은 아직 확정하지 않으며 비용 발생 작업은 수행하지 않는다.
4. 사진 없이 형태 예시로 시작할 수 있다. 허가와 정확 모델이 확보된 사진만 나중에 반영한다.
5. 이모지는 내 기기에 저장하는 반응으로 유지한다. 전체 이용자 수로 표시하지 않는다. 댓글·공개 집계는 후속 단계다.
6. 실제 광고와 쿠팡 링크는 공개·등록 후 정확한 모델/옵션과 고지를 검토해 활성화한다. 현재는 비활성 상태다.
7. 테크 소식은 모니터·디스플레이 관련 소식을 우선하는 보조 콘텐츠로 준비한다. 원문 링크·게시 시각·확인/갱신 시각을 구분한다. 기존 저장 목록은 보존하며 실시간 서비스로 표현하지 않는다. 새로운 수집이나 정기 실행을 승인한 것은 아니다.
8. 최종 확인 후 별도 공개 승인을 받고 승인 페이지에만 색인을 허용한다. 도메인 미정 동안 noindex를 유지하고 가짜 canonical·sitemap·운영 URL을 만들지 않는다.

이 결정은 **공개 후보의 범위와 준비 방향**에 대한 승인이다. 제품별 fact 검토·공식 출처·한국 SKU 동일성·공개 COMPATIBLE 승인과 별개다. 기존 원본 `public_status=UNKNOWN`과 사람 검토 보류 상태를 변경하지 않는다. 이 문서가 이전 출시 준비 설명보다 우선하며 과거 조사 기록은 보존한다.

## 별도 로컬 출시 미리보기 패키지

원래 `web/index.html`은 이전 맥북 중심 목업이다. 원본을 삭제하거나 덮어쓰지 않고 별도 디렉터리에서 현재 `monitor-v3.html`을 첫 화면 `index.html`로 복사한다. 따라서 기존 연구 화면이나 사용자 변경이 출시 후보에 섞이는 것을 줄인다.

실행:

```sh
python3 -m scripts.prepare_launch_preview --output /tmp/connectable-launch-preview-20261015
```

이미 존재하는 출력 디렉터리는 거부한다. 다시 만들려면 새로운 경로를 지정한다. 서버 실행·업로드·배포·외부 URL 접속은 수행하지 않는다.

- `site/`: 현재 화면의 명시적인 자산과 30종 정적 상세, 구매 가이드, 테크 소식, 상세에서 링크한 별도 공식 자료 보강 페이지. 이전 목업·관리 검토 화면·스크린샷·Python 파일·원본 research 폴더는 제외한다.
- `manifest.json`: 파일별 SHA256, 원본 진입점, 도메인 미정, 배포 승인 false를 기록한다. 문서 루트 밖에 저장하며 제품 정보의 새 기준 원본으로 쓰지 않는다.
- 소스와 복사본의 내부 경로·metadata를 기존 검사기로 확인한다. 모든 HTML에 noindex를 유지한다.
- 이 패키지 자체에 인증·호스팅 헤더·404 정책이 구현된 것은 아니다. 인터넷에 올려도 되는 배포 승인 산출물로 해석하지 않는다. 향후 접근 제한 미리보기는 호스팅의 인증과 보안 헤더를 함께 설정해야 한다.

## 공개 전에 진행할 순서

| 순서 | 준비/확인 | 현재 상태 |
| --- | --- | --- |
| 1 | 공개 후보 범위 및 첫 출시 기능 확정 | 이번 사용자 승인 기록 |
| 2 | 현재 디자인이 첫 페이지인 독립 패키지와 원본 보존 | 로컬 패키지 생성 및 검증 |
| 3 | 도메인·비용·호스팅 선택 | 도메인 사용자 결정 대기. 계정 생성·구매 없음 |
| 4 | 접근 제한된 미리보기에서 헤더·404·실제 URL·모바일 확인 | 호스팅 결정 이후. 로컬 검증으로 대체하지 않음 |
| 5 | 사용자에게 실제 후보를 보여주고 최종 공개 승인 | 보류 |
| 6 | 승인한 배포·canonical·sitemap·검색 도구 확인 | 보류. noindex 해제 없음 |
| 7 | 쿠팡·광고 연결, 사진·공개 참여 확장 | 후속 별도 준비 |
