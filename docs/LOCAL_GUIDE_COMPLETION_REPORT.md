# 로컬 구매 가이드 보완 보고서

작성일: 2026-10-13. 통합 작업의 구매 가이드 세션 기록이다. 전체 테스트 결과·최종 커밋·CI는 통합 보고서를 따른다.

## 변경 범위

[구매 가이드](../web/guides/monitor-buying.html)의 기존 해상도·주사율·USB-C 설명과 공식 근거 URL 3개를 보존하고, 네 번째 목차와 ‘비교표 읽는 법’ 섹션을 추가했다. 문구는 [제품 방향 v3](PRODUCT_DIRECTION_V3.md), [검증 상태 표시 기준](CONTENT_REVIEW_AND_DISPLAY_REPORT.md), [상세·비교 디자인 기록](MONITOR_DETAIL_COMPARISON_DESIGN_REPORT.md)의 기존 표시 정책을 소비자가 읽는 한국어로 정리한 것이다. 새 제조사 사양이나 제품 추천·성능 추정은 추가하지 않았다.

추가 설명은 다음 다섯 가지다.

- 미확인은 미지원이 아니며 부분 확인·검토 대기는 호환 보장이 아니다.
- 정확한 모델·지역·SKU 범위를 대조하며 해외 자료를 한국 판매 SKU로 승격하지 않는다.
- 정격(RATED)·최대 상한(UP_TO), PD 공급·소비전력·실제 충전 결과를 구분한다.
- 단위가 같아도 해상도·포트·동작 모드의 조건을 함께 비교한다.
- 공식 사양과 작성자·시험자의 관측을 분리하며 후기 하나를 호환 보장이나 구매 추천으로 바꾸지 않는다.

기존 공식 근거 링크 3개에 `target="_blank"`, `rel="noopener noreferrer"`와 눈에 보이는 ‘새 창’ 안내를 적용했다. 내부 목차·제품 목록 이동은 같은 탭을 유지한다. 기존 근거 확인일을 갱신하지 않았고, 새 섹션에는 사이트 표시 기준 정리일을 따로 표시했다.

[스타일](../web/guides/monitor-buying.css)은 기존 색상·카드·여백을 유지한다. 목차는 데스크톱 네 열, 중간 화면 두 열, 모바일 한 열이며 새 설명 다섯 묶음에 구분선을 사용한다. 제품 사진·광고·제휴 배너를 추가하지 않았고 `noindex,nofollow`도 유지했다.

## 검증

[브라우저 회귀](../tests/e2e/monitor-buying-guide.spec.js)의 기존 목차·접근성·반응형 검사를 네 번째 섹션까지 확장했다. 추가 테스트는 다섯 안내 제목과 지역·실수전 경계 문구, 공식 링크 3개의 새 창 보안 속성·안내, 실제 팝업 생성과 원래 가이드 탭 보존을 검사한다. 외부 제조사·지원 서버에 의존하지 않도록 팝업 응답은 테스트에서 가로챈다. 이 검사는 외부 문서의 최신 내용이나 사실성을 재검증하는 검사가 아니다. 데스크톱·모바일 프로젝트 양쪽에 적용된다.

세션에서 실행한 검사는 통과했다.

- `node --check tests/e2e/monitor-buying-guide.spec.js`
- 표준 라이브러리 HTML 파서 검사: 중복 ID 없음, 네 목차 앵커 존재, 내부 파일 경로 존재, 외부 링크 3개의 새 창·보안 속성 확인, `noindex,nofollow` 유지.

브라우저 전체 테스트와 Python 전체 테스트는 다른 세션과 서버 충돌을 피하기 위해 이 세션에서는 실행하지 않았다. 통합 담당자가 최종 변경 전체에 대해 실행한다.

## 보존 및 남은 범위

공식·연구·사이트 데이터, 후기 링크 데이터, 자동 생성 페이지·생성기, README·DECISIONS, 사용자의 기존 변경사항은 수정하지 않았다. 이 세션의 변경은 가이드 HTML·CSS·브라우저 테스트·본 보고서 네 파일이다. 실제 공개 배포·광고·이미지 권한·공개 호환 승인·main 병합은 진행하지 않았다. 가이드 설명은 비교 결과의 사용법이며 지역 SKU 동일성이나 실물 연결 성공을 대신하지 않는다.

통합 시 모바일 제목의 단어 단위 줄바꿈을 보완했다. 가이드 브라우저4개를 다시 실행해 모두 통과했고 최종 모바일 화면을 확인했다. 외부 근거의 기존 확인일은 새 정책 정리일과 구분해 유지한다.
