# 외부 후기 링크 플랫폼 검증 보강

## 범위

기존 RTINGS의 제품별 고정 경로와 퀘이사존의 원본 후기 참조 검증을 보존하고, 직접 확인한 YouTube·네이버 블로그·티스토리·개별 블로그 링크를 추가할 수 있도록 검증 계약을 확장했다. 후기 본문, 사진, 썸네일 및 영상을 복제하지 않으며 외부 후기와 공식 제품 사양을 합치지 않는다.

## 신규 플랫폼 계약

- [수동 확인 바인딩 원본](../data/research/monitor-review-link-bindings.json)은 제품 ID, 사이트, 정확한 URL, 확인 모델, 직접 확인 근거 위치 및 확인 날짜를 저장한다. 등록되지 않은 링크나 다른 모델로 바꾼 링크는 거부한다.
- YouTube는 `https://www.youtube.com/watch?v=`와 정확한 11자리 영상 ID만 허용한다. 공유 링크의 추적 매개변수나 다른 쿼리는 기준 URL에 저장하지 않는다.
- 네이버 블로그는 `blog.naver.com/계정경로/숫자게시물ID`, 티스토리는 단일 `*.tistory.com/숫자게시물ID`를 지원한다. 개별 블로그는 일반 도메인을 포괄 승인하지 않고 원문을 확인한 정확한 URL과 제품의 바인딩으로 제한한다.
- HTTP, 로그인 정보, 명시 포트, fragment, percent encoding, 추가 query, 위장 hostname 및 경로 이동을 거부한다. 영상 ID를 정규화 중 제거하지 않으므로 서로 다른 영상이 같은 URL로 합쳐지지 않는다.
- 파생 공개 자료에는 신규 플랫폼의 검증된 제품·사이트·URL 바인딩만 투영한다. 동적 화면도 이 목록에 없는 신규 플랫폼 링크를 표시하지 않는다. 공개 파일 자체가 함께 변조되는 상황을 인증하는 서명 체계는 이번 범위가 아니다.
- 후기 유형 enum은 기존 `FIRST_HAND_REVIEW`와 `PROFESSIONAL_REVIEW`를 유지한다. YouTube 표시 라벨만 '영상 리뷰'로 구분한다.

## 화면과 보존

원문 링크는 `target="_blank" rel="noopener noreferrer"`로 열며 새 창·새 탭 안내를 제공한다. 광고·제휴 여부 미확인을 유지할 수 있고 링크가 없는 모델은 다른 모델의 후기를 빌려 표시하지 않는다. 기존 후기 5건과 공식 사양 원본은 이 플랫폼 작업에서 수정하지 않았다.

## 검증

[Python 회귀 테스트](../tests/test_monitor_review_links.py)에 신규 플랫폼 허용, 원문 바인딩 누락·다른 모델 연결, 영상 query와 host 위장, 블로그 경로 제한, 근거 누락·잘못된 날짜·중복 바인딩 및 영상 ID 중복 규칙을 추가했다. 신규 6개 회귀 테스트가 통과했다.

[브라우저 회귀 테스트](../tests/e2e/monitor-review-links.spec.js)는 영상·블로그 허용과 불법 URL 차단, 새 탭·opener 분리, 임베드 및 이미지 비복제, 모바일 폭 보존을 검사한다. 후기 브라우저 테스트 12개(데스크톱·모바일)가 통과했다. 전체 실행 결과와 신규 수집 현황은 통합 보고서에 기록한다.

## 남은 제한

URL 문법과 모델 바인딩 검증은 재생 가능성, 공개 상태의 지속, 향후 리다이렉트, 리뷰 품질이나 한국 SKU 동일성을 보장하지 않는다. 접근 제한된 원문은 채택하지 않고, 모델이 확인되지 않는 자료는 등록하지 않는다. 플랫폼 정책 확인과 개별 원문 검토는 URL 형식 검증과 별도의 절차다.
