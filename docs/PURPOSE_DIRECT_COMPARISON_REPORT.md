# 용도 즉시 결과 및 직접 비교 진입

- 브랜치: `codex/monitor-purpose-design`
- 기준 커밋: `d521828`
- 날짜: 2026-10-11

## 변경

문서·사무, 게임 등 용도 하나를 누르면 기존 사양 필터를 적용하고 결과 영역에 포커스와 스크롤을 이동한다. 선택된 브랜드 및 검색어는 유지하며 세부 조건을 추가할 필요는 없다.

‘노트북 영상 연결’을 ‘맥북·맥미니’로 변경했다. 기존 USB-C DP Alt Mode 조건만 사용한다. Mac 전체 호환 제품 목록이나 HDMI 연결 가능 제품 전체를 뜻하지 않는다. 충전 및 실제 호환성 보장으로 승격하지 않는다.

메인 화면의 ‘모니터 골라 비교하기’에서 전체 30종 중 2~3개를 직접 선택한다. 기존 비교표와 미확인·지역·입력 조건 표시를 재사용한다. 필수 선택 누락과 중복 선택은 거부하고, 취소 시 기존 비교함은 유지한다. 상단 비교 버튼도 선택 제품이 부족하면 선택창을 연다.

## 검증

새 브라우저 회귀 테스트는 용도 선택 후 포커스·결과 제목 노출, Mac 라벨, 누락·중복 선택 거부, 2종·3종 비교 및 취소 시 보존을 데스크톱·모바일에서 검증한다.

첫 전체 실행은 169개 통과, 새 데스크톱 결과 이동 검사 1개 실패였다. 기존 CSS의 smooth 스크롤 영향을 없애기 위해 결과 이동을 instant로 명시했다. 테스트는 완화하지 않았다.

원본 제품 데이터, 조사 자료, 승인 상태, 기존 사용자 변경사항은 보존한다. main 병합 및 공개 배포는 하지 않는다.

최종 결과:
- `python3 -m unittest discover -s tests -q`: 546개 통과.
- `npm run test:e2e -- --workers=2`: 170개 통과 (사용자 로컬 변경 테스트 14개 포함).
- `python3 scripts/validate_local_site.py`: 통과.
- `python3 scripts/build_monitor_pages_v3.py --check`: 30개 정적 문서 일치.
- `git diff --check`: 통과.
- 데스크톱·모바일 실제 화면 확인. 원본 data 및 schemas 변경 없음.
