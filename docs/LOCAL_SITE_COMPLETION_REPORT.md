# 로컬 사이트 후속 작업 및 사용자 검토 목록

2026-10-11 · 기준 커밋 `ad75b4a` · `codex/monitor-purpose-design`.

## 이번 작업 진행바

`███` 3/3 구현 묶음 완료: 탐색·비교 편의 / 뉴스 탐색 / 통합 검증·인수 문서.

이는 이번 로컬 작업의 진행률이다. 공개 서비스·광고·수익화·제품 승인 완료율이 아니다.

## 구현

- 비교함: 같은 탭에서 뉴스·가이드를 다녀오거나 새로고침한 뒤에도 최대 3개 제품 유지. 탭을 닫으면 사라질 수 있는 sessionStorage를 사용하며 기기 간 공유는 아니다. 명시적인 비우기 버튼 제공.
- 저장 실패/손상: 기존 데이터를 덮어쓰지 않고 현재 화면의 비교만 허용한다. JSON 구조, 제품 ID, 중복, 3개 제한, 크기를 검사한다. 댓글 초안 저장소와 분리한다.
- 검색: 모델명·스펙 입력 예시 표시 및 Enter로 결과 이동. 기존 숫자·브랜드·조건 의미는 유지.
- 뉴스: 기존 RSS에 제목 검색과 출처 필터를 추가. 분류와 교집합으로 적용한다. 직접 확인한 신제품·사전예약 발표와 분리한다. 새 기사 수집이나 자동 운영은 하지 않았다.
- 모바일: 비교함 상태 안내와 비우기 버튼 추가 후 하단 레이아웃을 2행으로 정리했다. 자동 검사 외 실제 화면에서 세로로 찌그러지는 상태를 발견하여 수정했다.

## 사용자 확인이 필요한 것만

| 시점 | 확인할 내용 | 준비된 것 |
| --- | --- | --- |
| 로컬 사용감 검토 | 모바일 검색·비교가 편한지, 정보가 너무 많은지 | 모델/스펙 검색, 비교 선택창, 최대 3종 비교, 비교함 유지 |
| 공개 데이터 선정 전 | 한국 SKU 불확실 제품의 공개 범위와 최종 검토 | 출처·지역·미확인 상태 보존 |
| 실제 댓글 운영 전 | 공개 댓글 필요 여부, 신고·삭제 담당 및 보관 기준 | 현재는 로컬 초안과 도움 반응만 동작 |
| 이미지 적용 전 | 사용할 제품 이미지의 권리·원본 확보 | 임의 사진 대신 형태 예시 유지 |
| 뉴스 자동 운영 전 | 이용 조건·갱신 주기·원문 검토 책임, 네이버 API 발급 | RSS/공식 발표 분리 및 실패 상태 표시 |
| 나중에 | 도메인·호스팅, 쿠팡 사이트 등록·배너 ID, 공개 배포 승인 | 서버 API 코드와 정책 검토 문서. 실제 연결 보류 |

현재 추가 사용자 응답 없이 진행할 수 있는 이 문서의 로컬 기능 묶음은 마쳤다. 운영 정책을 임의로 결정하는 공개 댓글 서버나 실제 광고·색인은 켜지 않는다. 다음 단계는 사용감 피드백 또는 위 운영 항목의 결정에 따라 좁혀 진행한다.

## 보존 및 검증

README, DECISIONS, 기존 content-review 테스트와 site-v2의 사용자 미커밋 변경은 그대로 둔다. 원본 data/schema/아카이브를 수정하지 않는다. main 병합·공개 배포 없음. 브라우저 테스트가 생성한 기존 스크린샷만 실행 전 Git 상태로 복원한다.

추가 회귀 검사는 비교함 페이지 이동·비우기, 손상 보존, 저장소 차단, 검색 Enter 이동, 뉴스 출처+제목 필터와 발표 영역 분리를 데스크톱/모바일에서 확인한다. 실제 사용자 수·상품 판매량·호환성 정확도를 테스트 수로 승인하지 않는다.
