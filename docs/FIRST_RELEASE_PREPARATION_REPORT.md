## 승인과 수행 범위

사용자는 해외 공식 문서 기준 제품도 지역·미확인 표시를 붙여 공개 후보로 포함하고 나머지 추천 방향대로 준비하도록 승인했다. 도메인은 사용자 결정이며 실제 공개는 금지다. 이를 [첫 출시 준비 기준](FIRST_RELEASE_PREPARATION.md)에 기록하고 [제품 방향](PRODUCT_DIRECTION_V3.md)·[진행 현황](SITE_NEXT_STEPS_STATUS.md)에 연결했다. 사용자 미커밋 README·DECISIONS는 수정하거나 커밋하지 않았다.

## 구체적 준비

[패키지 생성기](../scripts/prepare_launch_preview.py)는 별도 로컬 경로에 현재 화면의 명시적인 파일만 복사한다. 기존 `web/index.html`을 보존하면서 후보 루트에 `monitor-v3.html`을 사용한다. 예전 목업·관리 검토 화면·연구 원본·스크린샷은 패키지에서 제외한다. 상세 화면의 추가 공식 자료 링크는 보존하기 위해 별도 10종 보강 페이지를 포함한다.

실제 출력은 `/tmp/connectable-launch-preview-20261015-final`에 생성했다. 문서 루트 `site/`의 55개 파일과 문서 루트 밖 SHA256 manifest를 생성했으며 서버 업로드는 없다. 도메인 null·배포 승인 false·전체 HTML noindex를 유지했다. 이 경로는 임시 로컬 산출물이며 보존을 보장하지 않는다. 동일 명령에 새로운 출력 경로를 지정해 재생성할 수 있다.

제품 원본의 UNKNOWN·부분 검토 상태를 바꾸지 않았다. 승인된 사진·공개 참여 집계·댓글·광고·Coupang 실제 링크·뉴스 자동 실행은 추가하지 않았다. 정적 사이트 준비 결정은 특정 호스팅 계약이나 유료 결제 승인이 아니다.

## 검증 결과

- 신규 회귀 6개: 현재 디자인 루트·과거 화면 제외, 30개 제품 상세 포함, 원본 바이트 보존·파일 hash, 공개 보류·noindex, 기존 출력 덮어쓰기 거부, 원본 내부 출력 차단, 잘못된 소스 검증 실패 시 출력 미생성.
- `python3 -m unittest discover -s tests -q`: **611개 통과**.
- `npm run test:e2e -- --workers=2`: **218개 통과**. 사용자 미커밋 테스트 14개 포함; 원격 브랜치 대상은 204개.
- 별도 후보 패키지를 127.0.0.1:8876에서 잠시 확인: 1440px/390px 루트 HTTP 200·30개 카드·PA279CRV 검색·정적 상세·미확인 표시·noindex·pageerror 0·가로 넘침 없음. 확인 후 임시 서버 종료. 기존 8875 미리보기는 보존했다.
- 패키지 생성 시 원본·복사본 모두 기존 로컬 metadata/경로 검사 통과. 추가 개인정보·비밀값 없음, 문서 상대 경로 및 git diff 검사 통과.
- 기존 data/schema 및 사용자 변경 43개 파일 SHA256 보존. 테스트 생성 캡처는 원래 기준으로 복원했다.

정확한 최종 커밋의 GitHub CI 결과는 해당 브랜치 Actions 및 완료 응답으로 확인한다. 테스트 통과는 실측·한국 SKU 동일성·제품별 공개 승인·이미지 사용권 확인을 뜻하지 않는다.

## 남은 단계

도메인·호스팅·예산 선택 이후 접근 제한 미리보기의 실제 URL·보안 헤더·없는 URL의 404·반환 HTML을 확인한다. 현재 패키지는 업로드 승인본이 아니며 공개 전 noindex 제거·canonical·sitemap·호스팅 접근 통제는 별도 구현과 검증이 필요하다. 사용자 최종 공개 승인 전 배포하거나 main에 병합하지 않는다.

새 사진 권리나 SKU 근거가 없으면 기존 표시를 유지한다. 지역 표시로 근거 없는 값이 정당화되지는 않는다. 뉴스 기존 저장 목록의 날짜를 새 확인 날짜로 바꾸지 않고, 새로운 모니터 중심 수집과 실제 운영 갱신은 후속 작업으로 남긴다.
