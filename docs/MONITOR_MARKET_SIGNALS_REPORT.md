## 공식 API 및 필요한 조건

[검색어 트렌드 공식 문서](https://developers.naver.com/docs/serviceapi/datalab/search/search.md)는 ratio를 구간 최대 검색량 기준 상대비율로 설명한다. [쇼핑인사이트 공식 문서](https://developers.naver.com/docs/serviceapi/datalab/shopping/shopping.md)는 쇼핑 검색 클릭 추이와 상대 클릭비율을 제공한다. 절대 검색 건수·제품 판매량과 구분해야 한다. 문서 샘플 숫자는 모니터 관측으로 저장하지 않았다. [공개 쇼핑인사이트](https://datalab.naver.com/shoppingInsight/sCategory.naver)는 데이터랩 통계와 쇼핑 랭킹 집계 로직이 별개라고 명시한다. 이번에 쇼핑 클릭 상대지수는 확보하지 않았다.

공식 API 수집에 필요한 조건은 소유자가 관리하는 네이버 계정의 앱 등록, Client ID/Secret 발급, 데이터랩 검색어트렌드/쇼핑인사이트 API 설정, 서비스 환경 등록이다. 등록 과정에 약관·계정 인증이 포함된다. 이번에 등록·권한 변경·API 호출을 하지 않았으며 계정의 실제 권한 상태 UNKNOWN이다. 쇼핑 API에는 모니터 분야 코드와 비교 키워드·공통 기간·기기·성별·연령 조건을 정해야 한다. 공개 웹 검색어 결과는 이번처럼 로그인 없이 확보 가능했으므로 계정을 모든 공개 조회의 선행 조건으로 간주하지 않는다.

절대 검색량·판매량의 공개 집계는 이번 조사에서 확보하지 못했다. 후속 수집에는 플랫폼이 제공하는 절대값의 단위·기간·대상 범위·사용 권한, 정확 SKU/판매처 식별, 리뷰 옵션 통합 범위, 광고·선택 정렬·개인화 조건 확인이 필요하다. 데이터랩 API 권한만 얻으면 실제 판매량·절대 검색량도 얻는다고 약속하지 않는다.
