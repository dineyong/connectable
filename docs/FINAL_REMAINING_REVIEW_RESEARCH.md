# 남은 정확 SKU 후기 최종 조사

확인일: 2026-10-13. [LG 직전 조사](MONITOR_REVIEW_LINK_BATCH_5_LG_REPORT.md)와 [Samsung 직전 조사](MONITOR_REVIEW_LINK_BATCH_5_SAMSUNG_REPORT.md)를 읽고 모델별 신규 검색 2조합으로 범위를 제한했다. 기존 보류·접근 실패 후보를 다시 열지 않았다. 검색 제목·요약은 발견에만 사용했다.

LG 검색 조합은 전체 SKU와 `review`(주요 판매점·제조사 도메인 제외), 전체 SKU와 `I / monitor / blog / review`를 사용했다. Samsung은 전체 SKU와 `review`(기존 PB Tech·제조사 제외), 전체 SKU와 `monitor / I / tested / youtube`를 사용했다. 각 모델 신규 유망 원문은 최대 2개 이내였으며 실제로 LG는 원글과 해당 댓글 영구주소, Samsung은 Umart 원문 1개를 직접 확인했다. 관련없는 판매점·상품 소개·제조사 사양 파일을 사용 근거로 수집하지 않았다.

## 혼합 모델 및 주장 경계

LG 원글 제목과 원글 작성자의 기기는 **35WN75C-B**다. 이번 근거는 다른 참여자가 **34WQ75C-B.AUS**를 직접 명시한 댓글 한 개다. 댓글 영구주소를 연결하고 원글의 USB-C 문제·충전 추론·모델 사양을 해당 제품에 옮기지 않는다. 정상 동작이라는 짧은 관측만 요약하며 해당 댓글에 없는 연결 포트·해상도·주사율·충전 성능은 채우지 않는다. `.AUS`가 호주 제조를 뜻한다는 댓글 작성자의 추정은 채택하지 않는다.

원글 전체 페이지에서 같은 참여자의 뒤늦은 사용 설명도 보였으나 해당 댓글 영구주소에서는 후속 답글이 펼쳐져 있지 않다. 이번 전달 후보는 최초 댓글에서 직접 보이는 구매 직후 관측만 포함한다. 장기 사용·수면 복귀·RJ45 경험을 추가 요약하지 않는다. 사이트 광고·작성자 협찬·제휴는 직접 확정하지 못해 `commercial_context=UNKNOWN`을 유지한다.

신규 후보는 통합용 임시 JSON에 전달했다. 이 조사 세션은 제품 원본·UI·Git을 수정하지 않았다. 개인명·닉네임·연락처·본문 전체·사진은 저장하지 않았고 로그인·CAPTCHA·접근 차단을 우회하지 않았다. 자료 부족은 제품의 실패·비추천·후기 부재를 뜻하지 않는다. 정식 데이터 반영, 참조 검증, 전체 테스트, push 및 CI 결과는 통합 세션에서 기록한다.
