## 광고 및 원문 확인 범위

CHIP 리뷰는 공개 원문을 일반 브라우저로 확인하고 선택 쿠키를 거부했다. 모델 전체 표기와 작성 매체의 실제 시험·사용 설명을 확인했다. 광고 영역 및 가격 모듈이 있어 `commercial_context=PRESENT`로 기록하지만, 해당 제품의 협찬·제공·제휴 여부를 확인한 것으로 표현하지 않는다. 체코어 자료이며 한국 판매 SKU와의 동일성을 승인하지 않는다.

별도 [27UP850K-W 후보](https://www.sarlt.com/lg-27up850k-w-review/)의 공개 원문 도구는 다른 도메인으로 리다이렉트했다. 제목·제품 소개는 확인했으나 원문 검토를 충분히 완료하지 못해 추가하지 않았다. 주소를 임의로 재작성하거나 링크 수를 늘리기 위해 채택하지 않았다.

YouTube는 제목·공개 설명·챕터만 확인했다. 전체 영상을 시청하거나 시험 결과를 재현했다고 주장하지 않는다. 자동 영상 요약은 근거로 사용하지 않았다. 후보별 정확한 모델과 지역 접미사 확인을 우선하고 전체 SKU 없는 가까운 모델은 배제한다.

## 보존 및 검증 경계

저장하는 것은 짧은 자체 안내, 정확 URL, 제품 바인딩, 확인 날짜·위치다. 작성자명·닉네임·연락처·사진·본문 전체·평점은 저장하지 않는다. 공식 사양·한국 SKU 상태·호환성 정책은 유지한다. 신규 후보 JSON 구문과 로컬 ID를 확인했다. 통합 참조 검증·브라우저 테스트·전체 테스트·push·CI는 통합 세션에서 확인한다. 이 조사 세션이 만든 임시 브라우저 탭만 닫았으며 사용자 탭은 보존했다.
