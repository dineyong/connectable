## 원문 확인 범위

11개 후보 링크, 10개 모델을 [통합 링크 원본](../data/research/monitor-review-links.json)에 통합했다. YouTube 9개와 한국어 개인 블로그 2개다. YouTube는 실제 공개 watch 페이지를 브라우저로 열어 제목과 게시자가 작성한 펼친 설명을 확인했다. 설명에 노출된 챕터가 있는 자료는 해당 항목도 확인했다. 전체 영상 시청·측정값 검증으로 해석하지 않는다. YouTube 자동 생성 요약은 근거로 쓰지 않았다.

PD2705U 두 블로그 글은 같은 작성자의 언박싱 및 후속 사용기다. 별개의 링크로 안내할 수 있으나 독립 사용자 사례 2건으로 계산하지 않는다. 원문 계정명·연락처를 별도 저장하지 않았고 이미지·썸네일·본문을 복제하지 않았다. 제품 제공·제휴 또는 판매 링크가 확인된 후보는 `commercial_context=PRESENT`로 기록했다. 이것은 모두 제품 협찬이 확인됐다는 뜻이 아니며 세부 근거와 미상 항목은 notes/evidence_location에 남겼다.

## 추가 제외 및 접근 결과

[GW2790Q/GW2790QT 비교 글](https://allggagi.tistory.com/entry/GW2790Q-vs-GW2790QT)은 실제 원문을 열었으나 사양 비교와 판매 안내 중심으로 본인 사용 근거가 부족해 제외했다. 제목이 후기여도 포함하지 않았다.

web 도구의 YouTube 원문 열람에서 내부 오류 또는 footer만 반환되는 경우가 있었다. 공개 브라우저에서 정상 watch 페이지를 직접 확인한 9건만 DIRECT_CHECK로 기록했다. CAPTCHA·로그인 요구·차단 우회·비공개 API·대량 수집을 수행하지 않았다. 제조사 페이지의 후기 목록에는 다른 모델 영상도 섞이므로 제조사 목록의 위치만으로 정확 모델이라고 인정하지 않았다.

후보는 공식 사양 또는 한국 SKU 검증 자료로 승격하지 않는다. 한국어 외 영상은 언어를 notes 또는 안내문에 보존하되 자료 내용을 번역·추정하여 제품 성능 사실로 추가하지 않는다. 최종 통합 검증·새 창 처리·CI 결과는 통합 보고서에서 기록한다.
