# 후기 보완 및 로컬 품질 후속 작업

2026-10-13. 브랜치 `codex/monitor-purpose-design`, 기준 커밋 `3954e15da3bbb504b77960493be0449e4a7d6141`. 사용자가 추가 확인 없이 가능한 작업을 이어가도록 요청했다. 기존 공개 승인·main 병합·광고 활성화 경계는 유지한다. 최종 커밋은 이 문서의 Git 이력으로 확인한다.

## 수행 결과

- [최종 SKU 조사](FINAL_REMAINING_REVIEW_RESEARCH.md): LG 34WQ75C-B.AUS 댓글 영구주소에서 전체 SKU·구매 직후·2021 MacBook Pro M1 본인 사용 관측을 확인해1건 추가했다. 원글의 다른 모델35WN75C-B, 댓글 작성자의 제조지역 추측, 직접 보이지 않는 장기 후속 내용은 가져오지 않았다.
- 기존34링크 객체를 보존해 **29종·35개 후기 링크**가 됐다. Samsung LS34C650UEEXXY 신규 원문은 제품 사양과 빈 후기 폼만 확인되어 보류한다. 새 근거가 들어오기 전 같은 후보를 반복 검색하지 않는다.
- [후기 연결 QA](REVIEW_LINK_POST_INTEGRATION_QA.md): 기준 시점34링크·28종의 원본/생성/정적/동적 일치를 확인했다. 실제 ComputerBase 상품 상세, 표시/보안 속성/빈 상태를 검토했고 화면 방어의 P2 불일치를 발견했다.
- 로컬8875 서버가 꺼져 연결 거부가 발생했다. 127.0.0.1에만 미리보기 서버를 복구했다. 외부 배포는 아니다.

## 재현한 결함과 수정

원본 검증기는 다른 모델의 RTINGS/퀘이사존 링크 연결을 거부하지만, 동적 화면은 해당 두 플랫폼의 URL 형식만 검사했다. 원본의 product_id만 다른 제품으로 바꾼 파생 입력이 화면에 표시될 수 있었다. 정상 저장 데이터에 오연결된 후기가 있다는 증거는 아니다.

수정 전 [Python 회귀](../tests/test_monitor_review_links.py)는 RTINGS5건·퀘이사존1건의 제품/URL 확인 목록 누락으로 실패했다. [브라우저 회귀](../tests/e2e/monitor-review-links.spec.js)는 M32U RTINGS 및 퀘이사존 링크를 Dell 제품에 복사한 입력에서 데스크톱·모바일 모두 실패했다.

[생성기](../scripts/build_monitor_review_links.py)가 검증된 모든 사이트의 정확 제품·사이트·URL 바인딩을 파생 자료에 투영하고, [화면](../web/monitor-v3.js)도 모든 사이트에서 동일 바인딩을 요구하도록 최소 수정했다. RTINGS 고정 원문 경로, 퀘이사존 원본 참조 및 신규 플랫폼의 직접 확인 등록 규칙은 그대로 유지했다. HTML/디자인/호환성 판정 엔진은 확대하지 않았다.

수정 후 후기 브라우저 검사14개 통과. 정상 기존 링크는 표시되고 교차 모델 입력은 숨겨진다. 이 목록은 서명이나 인증 수단이 아니다. 링크 객체와 확인 목록을 함께 위조하는 공격을 막는 것으로 주장하지 않는다.

## 실제 흐름 확인

사용 흐름은 모니터 목록에서 제품 상세를 열면 검증된 원본에서 생성한 JS 데이터를 읽고 정확 모델의 후기 원문 링크를 표시하는 것이다. API·데이터베이스·외부 인증키를 사용하는 흐름이 아니다.

| 경계 | 결과 | 근거 |
|---|---|---|
| 서버/페이지 | 통과 | `http://127.0.0.1:8875/monitor-v3.html` HTTP200 |
| 원본→생성물 | 통과 |35개 원본 검증·생성물 check, 전체35개 확인 바인딩 |
| 생성물→실제 상세 | 통과 | 실제 LG 상세에서 전체 SKU·커뮤니티 라벨·Reddit 댓글 영구주소1개 표시 |
| 외부 이동 설정 | 통과 | 전체35개 정적 링크 `_blank` 및 `noopener noreferrer`; 브라우저 회귀의 새 탭/opener 분리 |
| 런타임 | 통과 | LG 실제 상세 검사 pageerror0. QA의 ComputerBase 검토 화면 console error/warning없음 |

로컬 페이지 확인이 외부 원문의 지속 공개 접근이나 제품 성능 재현을 증명하지 않는다. 새 링크에는 원문에 없는 포트·해상도·주사율·충전 조건을 채우지 않았다.

## 남은 작업과 경계

사용자에게 다시 확인을 요청할 필요가 있는 로컬 수정 사항은 없다. 남은 후기1종과 한국 SKU/미확인 사양은 새로운 직접 근거가 있을 때 보완한다. 사진은 사용권 확보 전 형태 예시를 유지한다. 공개 이모지 집계·실제 댓글·도메인/배포/색인·쿠팡 배너 및 API 키를 요구하는 운영 연결은 기존 보류 상태다. 이를 임의 활성화하지 않는다.

진행 상태는 [현재 상태 문서](SITE_NEXT_STEPS_STATUS.md)의 최신 구간에서 확인하며 오래된 테스트 수치는 이전 이력이다. 로컬 자동 검사가 서비스 정확도·실물 시험·공개 보안감사를 대체하지 않는다.
