확인일: 2026-10-10. 작업 브랜치: `codex/monitor-comparison-v3-local`, 시작 커밋: `e722b5d`.

최신 사용자 요청에 따라 사이트 제작·로컬 반영 전에 세 시안을 먼저 제시한다. 기존 서버와 웹 파일은 변경하지 않았다. 현재 목표는 운영체제에 관계없이 모니터 사양을 비교하고, 간단한 도움 반응·짧은 의견을 남길 수 있는 사이트다. 기존 연구 자료는 보존한다.

## 세 가지 실제 이미지 시안

이미지는 ImageGen 기본 도구로 만든 디자인 예시다. 제품 렌더는 실제 제품 사진이 아니며, 버튼·댓글·공유 기능의 구현 증거가 아니다. 예시 제품의 최대 주사율은 입력별 조건을 생략한 카드 표현이므로 실제 구현에는 조건 링크가 필요하다. 임의 가격·별점·추천 순위·사용자 수를 넣지 않는다.

| 안 | 이미지 | 핵심 흐름 | 장점 | 주의점 |
|---|---|---|---|---|
| A 빠른 탐색형 | [시안 A](design/monitor-v3-options/a-fast-finder.png) | 검색 → 필터 → 카드 → 비교함 | 구매 목적 방문자가 빠르게 좁힐 수 있음 | 필터가 많아지면 초보자에게 부담; 기본·상세 분리 |
| B 가이드·후기형 | [시안 B](design/monitor-v3-options/b-editorial.png) | 선택 기준 → 제품 → 가이드·외부 경험 | 친근한 첫인상, 설명형 검색 유입에 적합 | 큰 히어로가 제품 탐색을 밀어내지 않도록 축소 |
| C 정밀 비교형 | [시안 C](design/monitor-v3-options/c-comparison.png) | 제품 선택 → 같은 항목 비교 → 조건·출처 확인 | 사이트의 핵심 기능이 명확함 | 다른 단위·지역 SKU·미확인 값은 자동 우열 비교 금지 |

추천은 **홈에 A, 가이드·후기 구역에 B의 분위기, 비교 페이지에 C**다. 세 개를 별도 디자인 시스템으로 구현하지 않고 하나의 타이포그래피·색·간격 체계로 통일한다. 사용자 선택 전 실제 사이트를 교체하지 않는다. [생성 프롬프트](design/monitor-v3-options/prompts.md)에 재현 의도를 보존한다.

## 구현할 때의 UX·데이터 기준

- 모바일: 카드 1열, 필터는 닫을 수 있는 패널, 비교함은 화면을 가리지 않는 하단 영역. 비교표는 항목명 고정과 가로 이동을 검토한다. 아직 모바일 구현·검증은 하지 않았다.
- 미확인은 미지원과 다르다. 필터에 미확인 포함 여부를 명시하고, 비교에서 빈 값을 0으로 만들지 않는다.
- 공식 사양과 외부 후기, 자체 댓글은 별도 구역으로 표시한다. 반응은 ‘정보가 도움이 됐는가’이며 제품 품질·구매 인증을 뜻하지 않는다.
- 사양 단위와 입력 조건을 같이 표시한다. 최대 주사율, 전력의 RATED/UP_TO, 지역 SKU 상태를 보존한다.
- 광고는 콘텐츠와 구분된 자리만 설계한다. 광고 스크립트·제휴 링크·공개 승인·배포는 활성화하지 않는다.
- SEO/GEO는 검색 가능한 제품별 문서, 명확한 표, 출처·확인일에 기반한다. 뉴스는 현재 로컬 피드 실험과 운영 수집을 구분한다. 검색 노출·실시간성을 보장하지 않는다.

5. 제품 URL·메타데이터·정적 콘텐츠·접근성·SEO 검증. 공개 도메인·배포는 별도 단계.
