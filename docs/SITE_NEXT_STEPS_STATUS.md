## 사용자에게 필요한 결정만

지금 답변이 없어도 로컬 기능은 계속 사용할 수 있다. 아래는 공개 출시 전에 필요한 결정이다.

1. **공개 제품 범위:** 한국 SKU 확인 제품부터 공개할지, 해외 공식 문서임을 분명히 표시한 제품도 포함할지. 어떤 선택도 미확인 값을 승인된 사실로 바꾸지는 않는다.
2. **도메인·호스팅·출시 시점:** 실제 공개 승인과 운영 환경. 현재 noindex 및 로컬 전용 상태 유지.
3. **이미지:** 직접 촬영본 또는 상업 이용을 허가받은 자료가 있는지. 없으면 형태 예시 유지.
4. **수익화 연결:** 도메인 결정 후 쿠팡 사이트 등록·계정 설정. 키는 채팅/저장소에 전달하지 않는다. 실제 배너 연결은 이미 나중으로 결정됨.
5. **뉴스 API(선택):** 네이버 검색 API를 사용할 경우 계정 발급·안전한 비밀값 설정 필요. API 없이 가능한 공식 출처 조사와는 별개다.

댓글 도입 여부, 디자인 재승인, 이모지 우선 여부를 다시 묻지 않는다. 이미 정해진 결정은 유지한다.
