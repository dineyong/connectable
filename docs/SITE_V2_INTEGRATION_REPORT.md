# Connectable v2 통합 검수 기록

2026-10-08 · research/question-corpus-foundation · 로컬 구현 검수.

## 통합 범위

[제품 방향 v2](PRODUCT_DIRECTION_V2.md)에 따라 [표시 콘텐츠](SITE_CONTENT_V2_REPORT.md)와 [새 홈](SITE_V2_IMPLEMENTATION_REPORT.md)을 연결했다. [품질 계획 및 검수](SITE_V2_QA_MONETIZATION_PLAN.md)는 준비·수행·미수행 영역을 구분한다. 모니터 3개와 연결 연구 기록 38건, 가이드 3개다. 제품 카드에 직접 연결된 후기는 0건이며 다른 모델을 유사 이름으로 붙이지 않는다. 가격·평점·추천 순위·독립 사용자 수를 만들지 않았다.

이전 홈은 /legacy.html로 보존했다. 기존 tests/e2e/mockup.spec.js의 두 page.goto만 /에서 /legacy.html로 이관했다. 기존 검사 내용이나 기준을 완화하지 않았다. 새 홈과 내부 검토 화면은 별도 테스트 대상이다.

## 검증 이력

- `python3 scripts/build_site_content_v2.py --check`: 재생성 일치.
- `python3 -m unittest discover -s tests -q`: 313개 통과, v1 한국어·영어 예시와 정식 v2 검증 유지.
- 최초 전체 브라우저 실행은 50개 통과·2개 trace artifact ENOENT로 실패했다. 검증 도중 같은 출력 디렉터리를 사용하는 병행 실행과 충돌했을 가능성이 있어 별도 출력 경로로 재실행했다. 단언 실패를 수정하거나 제외한 것이 아니다.
- `npm run test:e2e -- --workers=2 --output=/tmp/connectable-v2-integration-results`: 수정 전 기능 기준 전체 52개 통과(15.1초).
- 원본 data/schema 17파일 SHA-256: 기존 확인 스냅샷과 전부 일치. archive/site-v1-20261008의 manifest 8개 파일 모두 일치.
- 관련 새 문서 내부 파일 경로와 `git diff --check`: 오류 없음.

## 통합 중 발견한 사항

동일 원문이 PUR-009와 UQ-0009에 중복돼 있다. 두 연구 기록은 관측·목적이 다르므로 원본에서 삭제하지 않는다. 사이트 표시만 원문별로 묶어 두 기록을 열람할 수 있도록 화면 세션에 수정 요청했다. 38기록은 사용자 38명 또는 독립 후기 38건이 아니다. 같은 원문을 제외한 그룹은 37개이며 내용상 독립성 추가 검토가 필요하다.

모니터 섹션의 ‘같은 모델의 연결 경험을 함께 확인’ 문구는 현재 직접 연결 후기 0건보다 앞선 표현이라 자료 상태에 맞게 교정 요청했다. 해당 후속 수정과 회귀 결과는 완료 후 추가한다.

## 남은 작업

실제 제품 사진은 권리 확인이 필요해 현재 개념도를 사용한다. 후기 제출·회원·자유 댓글 서버는 이번 범위에서 제외됐다. 실제 국내 변형과 해당 모니터의 맥북 후기를 확보하는 것은 후속 편집 작업이다. 애드센스·쿠팡파트너스 계정·최신 정책·공개 도메인·개인정보 안내·배포 검증은 별도 단계이며 수익이나 승인 완료를 주장하지 않는다. main merge, 공개 배포, 외부 광고·제휴 코드 연결은 수행하지 않았다.

## 후속 수정 및 최종 회귀

화면 담당이 동일 원문 카드 그룹과 PUR-009↔UQ-0009의 상세 상호 링크를 구현했다. 원문37그룹/연구38기록을 구분하며 원본JSON38기록은 바꾸지 않았다. URL 추적 파라미터·fragment·끝 slash 중복 처리 회귀를 추가했다. 모니터 섹션은 정확히 연결된 후기가 없다는 사실을 명시한다. 새 홈22·내부검토22·보존홈12 검사로 확대됐다.

`npm run test:e2e -- --workers=2 --output=/tmp/connectable-v2-final-results` 최종 56개 통과. Python313개·재생성 일치·diff검사도 재통과했다. 로컬홈 HTTP200. 최종품질세션의 후속판정은 담당QA문서에서 확인한다. 현브랜치 HEAD52a8bc3 유지, 이단계 commit/push 없음.
