# 용도 우선 모니터 디자인 적용

2026-10-11. 사용자 제공 Claude 목업 B(용도부터)를 기준으로 로컬 v3 화면을 변경했다. 브랜치 `codex/monitor-purpose-design`, 기준 `a134b0e`.

- 연한 회녹색 배경, 짙은 녹색, 노란 비교 버튼과 제목 강조, 가로 제품 목록을 적용했다.
- 용도 바로가기: 문서·사무는 가로≥2560/세로≥1440 및 최대 주사율≤120Hz, 게임은≥144Hz, 사진·영상은3840×2160, 노트북 연결은 기존 명시적 USB-C DP Alt Mode 필터다. 근거 없는 추천점수, 충전 보장, 색 정확도 판정을 만들지 않는다. 미확인 값은 용도 선택 시 제외하며 수동으로 포함 가능하다.
- 용도 변경은 사양 필터를 교체하고 브랜드·검색 조건은 유지한다. 직접 사양 조건을 바꾸면 용도 선택 강조가 해제된다. 전체 보기는 기존 초기화 동작을 사용한다.
- 데스크톱 오른쪽 비교함, 모바일 하단 비교 버튼, 기존 브랜드 다중선택·묶음·상세·비교 기능을 유지했다.
- 원본 데이터, 보강 자료, 기존 다른 화면은 변경하지 않았다. 새 스타일은 `monitor-purpose.css` 및 해당 body 클래스로 격리했다.
- 실제 광고·가격·별점·가짜 뉴스·제휴 링크는 추가하지 않았다. 뉴스는 기존 화면으로 연결한다.

검증: `python3 -m unittest discover -s tests -q` 520개 통과(48.137초), `npm run test:e2e` 136개 통과(46.0초). 새 용도 테스트는 실제 원본 필터값과 표시 제품 ID 전체를 대조한다. 기존 브랜드·검색·비교·미확인·접근성·모바일 회귀를 포함한다. 사용자 미커밋 테스트14개는 이번 커밋에 포함하지 않아 원격 브라우저 대상은122개다.
