## 공통 원칙

- 링크는 새 탭 요청(`target="_blank"`)과 `rel="noopener noreferrer"`를 사용한다. 실제 탭/창 선택은 브라우저 설정에 따른다.
- 공식 사양과 후기 내용을 구분한다. 후기 링크를 제품 별점·공식 기능·호환 승인으로 해석하지 않는다.
- 본문·사진·썸네일을 복제하지 않는다. 공개 원문 URL과 직접 작성한 짧은 안내를 사용한다.
- 모델·리비전이 불확실한 자료는 특정 제품의 후기 카드에 자동 연결하지 않는다.
- 협찬·광고 미상은 미상으로 유지한다. 링크 수나 긍정 후기 비율을 인기도로 표시하지 않는다.
- 기존 사용자 변경·원본·충돌을 보존한다. main 병합·공개 배포 없이 작업 브랜치에만 push한다.
- 반복 조회 대신 근거가 새로 확보된 항목을 배치 처리한다. 전체 테스트와 CI는 통합 후 한 번 실행한다.

후기 링크 배치 결과와 다음 작업은 [진행 상태](SITE_NEXT_STEPS_STATUS.md)에 기록한다. 이전 세션 이력은 [로컬 MVP 진행](LOCAL_MVP_SESSION_PROGRESS.md)에 보존한다.

- 조사 A: ASUS·BenQ·Dell 15종의 영상/블로그 후보 검토.
- 조사 B: LG·MSI·Gigabyte·AOC·Samsung 15종의 영상/블로그 후보 검토.
- 플랫폼: YouTube의 영상 ID 쿼리, 블로그의 정확 URL/모델 근거 등록, 표시·브라우저 회귀 검사.
- 통합: 초기5링크 보존, 직접 확인한 후보만 원본과 등록표에 추가, 생성물·전체 테스트·push·CI 확인.

모델 접미사·지역 SKU·리비전 불확실 자료는 원문을 확인했어도 연결하지 않는다. 유튜브 원문 확인 범위는 제목·설명·챕터 또는 실제 시청 범위를 기록하며, 제목·설명을 확인한 것을 전체 영상 시청으로 표현하지 않는다. 새 링크는 원문으로 이동하는 텍스트 안내이며 썸네일·본문·영상 복제를 하지 않는다.
