# 의사결정 기록

## ADR-001: 앱보다 데이터와 판정 규칙을 먼저 구축한다

- 날짜: 2026-10-07
- 상태: 승인

### 결정

UI와 제품 코드를 만들기 전에 서비스 범위, 출처 정책, 데이터 구조,
호환성 판정 규칙과 초기 검증 데이터를 준비한다.

### 이유

사이트의 경쟁력은 화면 디자인보다 판정의 정확성, 근거의 추적 가능성,
실사용 데이터 축적에서 발생한다.

## ADR-002: MVP는 Apple Silicon 맥북과 외장 모니터로 제한한다

- 날짜: 2026-10-07
- 상태: 승인

### 결정

최초 버전은 Apple Silicon MacBook Air와 MacBook Pro의 외장 모니터
연결 문제에 집중한다.

### 이유

제품군을 제한해야 공식 사양과 실제 사례를 충분히 검증할 수 있다. 전체
Windows 노트북까지 동시에 지원하면 모델 변형과 포트 사양 불확실성 때문에
초기 판정 품질이 떨어진다.

## ADR-003: AI는 판정자가 아니라 조사·정리 보조로 사용한다

- 날짜: 2026-10-07
- 상태: 승인

### 결정

AI가 생성한 호환성 답변을 직접 공개하거나 데이터베이스의 확정값으로
저장하지 않는다. AI는 출처 후보 수집, 모델명 정규화, 중복 탐지, 설명문
초안에만 사용한다.

### 이유

잘못된 긍정 판정은 불필요한 구매와 서비스 신뢰 하락으로 이어진다.

## ADR-004: 일반 댓글과 구조화된 연결 결과를 분리한다

- 날짜: 2026-10-07
- 상태: 승인

### 결정

질문·대화용 댓글과 성공·제한·실패를 기록하는 구조화된 사용자 사례를
별도 데이터로 운영한다.

### 이유

자유 형식 댓글만으로는 제품 모델과 연결 조건이 빠져 판정 근거로 재사용하기
어렵다.
