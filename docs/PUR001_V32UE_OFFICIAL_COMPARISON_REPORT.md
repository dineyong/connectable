확인일: 2026-10-08. 작업 브랜치: research/question-corpus-foundation. 기준 HEAD: 52a8bc3. 로컬 검토 문서이며 공식 catalog 등록, 호환성 승인, 실물 재현 결과가 아니다. 공개 판정 UNKNOWN, 사용자 사례 C등급, 승인 골든 0/30을 유지한다.

모든 확인일은 위 날짜다. 최신 지원 안내를 2021년 후기의 OS나 당시 수행 절차로 소급하지 않는다. 실제 소유 장치의 리비전·펌웨어·OS 버전은 미상이며 제품군 문서가 특정 장치 조합을 보증하지 않는다. 별도 판매 링크, 로그인 제한 우회, 공식 사양 추정은 사용하지 않았다.

## 두 연결의 분리

- **R 구성 — 공개 PUR-001:** M1 Air → 모니터 동봉 USB-C 케이블 → V32UE. 작성자는 맥북 내장 화면을 보조 화면으로 사용하는 방식과 영상·충전을 보고했다. 케이블 SKU·길이, 실제 신호 주사율·충전 전력은 UNKNOWN이다. 클램쉘의 장점 언급을 정확한 닫힌 덮개 시험 결과로 전환하지 않는다.
- **U 구성 — 비공개 사용자 대화:** M1 Air → 코드웨이 C-C 케이블 → V32UE. 사용자가 닫힌 덮개에서 영상·충전을 사용한다고 보고한 별도 구성이다. 제품 구매 페이지는 재확인하지 않았다. 상품 표기의 USB4·Thunderbolt 4 호환·8K·240W·40Gbps는 미검증 광고 정보다. SKU·리비전·실제 Hz·전력은 UNKNOWN. 길이 표기 “1.2mm”에 대한 1.2m 확인 답변이 없어 길이도 UNKNOWN이다. 공개 코퍼스·검토 UI에 가져오지 않는다.

공식 근거: [M1 Air 사양](https://support.apple.com/ko-kr/111883), [V32UE 제조사 자료](https://www.jooyon.co.kr/bbs/board.php?bo_table=press&page=16&wr_id=227). 닫힌 덮개 조건은 [외장 화면 안내](https://support.apple.com/ko-kr/102501), 허용 거부 상태에서도 충전될 수 있다는 구분은 [액세서리 안내](https://support.apple.com/ko-kr/102282)에 따른다. 충전 표시만으로 영상 허용·영상 정상까지 확인하지 않는다.

확인한 범위에서 영상·충전 기능과 사용자 보고 사이에 직접 충돌은 발견하지 않았다. 자료 부재는 INCOMPATIBLE의 근거가 아니다. DP1.2·HDMI2.0 포트 소개를 USB-C의 DisplayPort 버전으로 옮기지 않으며, 다른 모니터 모델의 사양도 적용하지 않는다. 포트별 픽셀 타이밍·PD 전압/전류 프로파일·실제 케이블 식별·펌웨어별 동작은 남은 결측이다.
