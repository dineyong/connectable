# Connectable 제품 방향 v3 — 모니터 사양 비교

확정일: 2026-10-10. 상태: 사용자 승인. 현재 제품 목표·개발 순서의 기준 문서다.

## 목표와 대상

모니터 구매자가 제품의 사양 차이를 쉽게 비교하고 선택하도록 돕는 한국어 사이트를 만든다. 대상은 특정 운영체제나 노트북에 한정하지 않는다. 맥북·윈도우 연결 사례는 제품 상세의 참고 정보로 활용한다. 정보성 콘텐츠와 구매 동선을 통해 애드센스·쿠팡파트너스 수익화를 준비하되 수익·계정 승인·트래픽을 보장하지 않는다.

1차 핵심은 모니터 탐색, 2~3개 제품 사양 비교, 정보에 대한 도움됐어요 반응과 짧은 댓글이다. 복잡한 연결 판정·구조화된 사용자 실사용 보고·대규모 커뮤니티는 첫 출시의 필수 조건에서 뺀다. 기존 호환성 승인 보류 정책은 바꾸지 않는다.

## 문서 우선순위와 기존 자료

제품 기능·타깃·개발 순서는 이 문서와 [진행 계획](MONITOR_COMPARISON_V3_ROADMAP.md)을 우선한다. [Baseline v1](PROJECT_SCOPE.md), [초기 작업 지침](PROJECT_INSTRUCTIONS.md), [제품 방향 v2](PRODUCT_DIRECTION_V2.md)의 이전 기능 범위·일정은 역사적 기록이다. 그 문서의 출처·개인정보·기존 변경 보존·불확실성·Git 안전 원칙은 계속 적용한다.

기존 data/official, data/research, data/site, schemas, scripts, tests, archive 및 조사·검토 문서를 삭제하지 않는다. 질문 100건 수집 완료, 사람 검토 완료 또는 정식 호환성 판정 승인으로 상태를 바꾸지 않는다. 원본 사양·관측·댓글은 분리한다. 새 화면용 파생 구조가 필요하면 별도 설계 후 기존 파일을 보존한다.

## 첫 출시 기능

| 영역 | 포함 범위 | 완료 기준 |
|---|---|---|
| 모니터 탐색 | 모델 검색, 크기·해상도·주사율·패널·포트·부가기능 필터 | 실제 확보한 데이터만 검색·필터링; 미확인 조건은 확인된 결과에 포함하지 않음 |
| 제품 카드·상세 | 핵심 사양, 공식 출처·확인일, 세부 조건·미확인 정보 | 제조사 표기/실사용 관측 분리; 지역·SKU 범위 표시 |
| 비교 | 2~3개 선택, 차이점 강조, 같은 항목과 단위로 표시 | 패널/포트별 최대·동시 조건을 섞지 않음; 숫자 미상은 미상 유지 |
| 가벼운 반응 | 정보가 도움됐어요 버튼, 짧은 댓글 | 페이지·제품 정보에 대한 반응이며 구매/사용 인증·제품 별점이 아님 |
| 구매 가이드 | 화면 크기·해상도·주사율·포트 등 선택 기준 | 기존 자료 기반 고유 설명, 사양·추론 구분 |
| 판매처·광고 | 정확한 모델·옵션의 제휴 링크, 고지, 보조 광고 영역 | 링크 검토·계정/정책 확인 후 활성화; 수수료로 비교 순위를 결정하지 않음 |

모든 비교 항목이 현재 제품 6종에 채워져 있다는 뜻은 아니다. 스키마·공식 근거·결측 상태를 먼저 매핑한다. 소비전력과 PD 공급, 정격과 최대, 패널 주사율과 입력 포트 주사율은 구분한다. 지역별 모델 명칭을 자동 동치로 처리하지 않는다.

## 반응·댓글의 최소 운영 기준

첫 화면은 익명 또는 별도 가입 없이 이용하는 방향을 우선 검토한다. 회원가입·프로필·팔로우·자유 게시판·구매 인증·별점·사진 후기·댓글 답글 계층은 1차 필수 기능에 포함하지 않는다. 최소 저장·중복 반응 억제·입력 길이·스팸 제한·신고/삭제·검토·개인정보 처리 방식을 구현 전에 설계한다. 실제 서비스를 위한 저장 방식과 운영 권한은 아직 결정하지 않았다.

로컬 브라우저 저장만으로 구현하는 시연 기능은 같은 기기의 임시 반응임을 표시한다. 이를 전체 사용자 참여 수로 표시하지 않는다. 사용자 댓글을 자동 공식 사양이나 호환성 근거로 승격하지 않는다. 실명·이메일·전화번호 입력을 요구하지 않고, 공개 댓글의 개인정보·외부 홍보 링크를 검토한다. 가짜 참여 수·후기·구매 결과를 생성하지 않는다.

## 디자인 기준

[사용자가 승인한 이미지 목업](design/monitor-comparison-v3-concept.png)을 시각 방향의 기준으로 보존한다. 이미지 제품과 숫자는 배치 예시이며 원본 데이터가 아니다. 구현에서는 실제 근거와 미확인 상태로 대체한다.

밝은 배경·절제된 파란색·넉넉한 여백·읽기 쉬운 비교표를 사용한다. 데스크톱은 필터와 제품 카드, 비교표를 중심으로 구성하고 모바일은 필터 접기 및 비교 열 전환을 검토한다. 키보드 조작, 초점, 대비, 체크박스/버튼 이름, 빈 결과를 검증한다. 광고는 핵심 비교 행과 조작 영역을 가리지 않는다. 기존 사이트 화면과 테스트를 참고·보존하며 새 방향 구현 전 버전 보존 방식을 정한다.

## 후순위와 승인 경계

연결 경로 엔진 확대, 골든셋 승인 확대, 질문 21~100 추가 수집, 대량 제품 수집, 실시간 가격 추적, 개별 Windows 기기 전수 판정은 보류한다. 기존 모니터 사양의 미확인 필드만 필요에 따라 공식 자료로 보완한다.

이번 사용자 승인은 제품 방향과 목업 진행에 대한 승인이다. 공식 사양 사람 검토, 한국 SKU 동일성, 물리 충전 결과, 공개 COMPATIBLE, main 병합, 실제 배포·광고·제휴 활성화의 승인이 아니다. 새 목표 진행을 오래된 경로 연구 완료에 묶지 않되, 비교 화면에 사용할 사실의 근거·검토 상태는 유지한다.
