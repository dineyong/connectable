## 등록 계약과 수동 검수 책임

후기 검증기는 제품 존재 여부, 원본 표시 모델과 `checked_model`의 정확 일치, `DIRECT_CHECK`, 확인일, `EXACT_DOCUMENT_MODEL`, 원문별 URL·제품·모델 바인딩을 요구한다. `Forum`·`Blog` 등은 정확 URL을 등록해야 하며 사이트 도메인 전체를 승인하지 않는다.

그러나 문자열이 일치하도록 작성된 `checked_model`만으로 원문에 해당 모델이 실제 존재했다고 기계가 확인할 수는 없다. 사람 또는 조사 세션의 원문 직접 확인과 `evidence_location`이 필요한 이유다. 검색 제목·요약, 판매 페이지 MPN, 다른 지역 접미사, 일반 S65UC 제품군을 결합해 정확 SKU를 재구성하면 안 된다.

2. 같은 근거 맥락에서 작성자의 실제 구매·설치·사용 또는 전문 리뷰의 실제 시험 사실이 확인된다. 단순 구입 예정·상품 소개·타인 조언은 제외한다.

5. 광고·판매·제휴를 직접 확인하지 못하면 `UNKNOWN`을 유지하고 개인정보·원문 전체·이미지를 수집하지 않는다.
6. 접근 실패·로그인·CAPTCHA는 우회하지 않으며 검색 요약으로 빈칸을 보충하지 않는다.
