## 사례별 검수

- **UQ-0013:** 최초 미상 듀얼 HDMI 장치와 j5create 장치를 별도 노드·구성으로 분리했다. 첫 외장 두 화면의 복제와 최종 서로 다른 세 작업 화면은 원문의 명시적 보고에 근거한다. 외장 mirrored=2는 복제 그룹 전체 대수이며 independent_extended=0과 중복되지 않는다. 최종 외장 independent_extended=2, mirrored=0은 내장 화면을 제외한 요약 해석으로 표시했다. USB 3.0 명칭만으로 USB-A 커넥터·DisplayLink·드라이버를 확정하지 않았다. 정확한 케이블 경로는 UNKNOWN_GAP이다. 첫 장치의 실패 표현은 목표 미달 관측으로 남겼으며 별도 종결 선언을 추가하지 않았다.
- **UQ-0015:** macOS 메뉴의 U2415 인식과 실제 검은 화면을 각각 관측으로 분리했다. 본문에 작성자의 입력 선택 상태가 이미 명시되어 있다. 공개 타인 답변은 컨버터 종류·지원 안내 점검 조언이며 입력 선택 실행·해결 보고가 아니다. ADVICE는 실제 시도에 포함하지 않았고 UNRESOLVED를 유지한다.
- **UQ-0017:** 문제 계정·정상 인식 비교 계정·재로그인 후 배경화면만 표시되는 상태·최종 해결 보고를 분리했다. 점검 목록 내부 순서는 UNORDERED, 댓글에서 일부 전후만 확인되는 관측은 RECONSTRUCTED_PARTIAL이다. 타인의 설정 파일 제거 조언을 작성자 실행으로 바꾸지 않았다. 최종 성공은 명시됐지만 구체적 해결 조치가 없어 최종 실행 시도는 만들지 않았다. 듀얼의 내장 포함 여부·외장 대수는 UNKNOWN이며 수치가 없다. 최종 성공 보고만으로 NORMAL 신호 수치를 추정하지 않는다.
- **UQ-0019:** 메뉴의 1080 선택 상한과 현재 영상·웹서핑 사용 보고를 분리했다. 실제 픽셀 해상도·주사율·정확한 점등 대수는 미상이다. 2556*1440은 작성자의 과거 기억 라벨 그대로 근거 요약에 남겼고 2560x1440으로 자동 수정하지 않았다. 드라이버 재설치·Windows 점검만 실행 시도로 표현했다. 다른 케이블·그래픽카드 구매는 계획이며 실행·포기 확정이 아니다.
- **UQ-0020:** 데스크톱 첫 연결·모니터 추가 전원 연결·삼성 노트북 정상 출력 비교를 분리했다. 구성마다 소스 기기가 하나이며 비교 구성은 별도 SOURCE 노드를 사용한다. HDMI 끝을 PC에 연결한 물리 배치를 기록하되 변환 방향 지원·기능·프로토콜의 호환 사실로 해석하지 않았다. 추가 전원은 모니터 POWER 경로이며 소스 PD는 UNKNOWN이다. 계속 해결 방법을 묻는 무신호 관측은 FAILURE나 포기 결론이 아니다.
- **UQ-0023:** C to DP 외장 4K 60Hz 출력 정상과 YouTube 4K 재생 끊김은 별도 관측이다. HDR 활성·해제 구성과 해제 후 정상 재생을 분리했다. 최종 댓글에 반복되지 않은 실제 Hz·해상도는 최초 수치를 복사하지 않았다. HDR 목표는 남아 있으므로 전체·최종 구성 결과는 LIMITED_SUCCESS다. CPU 10세대 확인만 반영하고 타인의 VP9·가속 조언을 실제 설정 변경으로 만들지 않았다.

## 스키마 한계와 3차 배치

**보류 0건, 3차 배치 전 필수 스키마 수정 없음.** 여러 소스의 비교도 구성당 소스 하나 규칙과 부분 경로로 표현할 수 있다.
시스템 인식·영상 출력·재생 품질은 서로 다른 의미이며 현재 summary와 설정을 함께 읽어야 한다.
특히 UQ-0023의 재생 끊김은 영상 전송 무신호가 아니므로 signal_state=NORMAL을 유지하고 재생 문제를 별도 관측 summary로 보존했다.
1차 오디오 관측 한계와 마찬가지로 기능별 자동 집계에는 한계가 있다. 향후 최소 후보는 선택 observation aspect와 기능별 상태이지만 이번에는 채택하거나 스키마를 수정하지 않는다.
UNKNOWN 신호 상태의 최종 SUCCESS도 작성자의 해결 선언을 보존하는 것이며 정량 성능 성공을 뜻하지 않는다.

남은 결측은 세부 SKU·케이블 실물 동일성·입력 단자 세부·프로토콜·드라이버·OS 버전·시험일·일부 화면 수·모드·PD다.
작성자 기기 역할·계정 비교·광고성 해석·원문의 향후 수정은 사람 검수가 계속 필요하다.
전체 16건은 C/NEEDS_REVIEW/NO/NOT_CHECKED이며 공식 대조 전 호환 판정에 사용할 수 없다.
