# 출시 후보 검수 및 이미지 사용권 통합 결과

2026-10-15 · 작업 브랜치 `codex/monitor-purpose-design` · 검수 기준 `bfc4127290bc52ec125656bbedbfa95475083514`.

## 결론

현재 로컬 출시 후보의 구매 동선 검수는 통과했다. 검색 라벨과 미리보기 안내의 접근성 문제 2건을 최소 수정했다. 제조사 8곳의 공개 정책·미디어 경로를 확인했지만 상업 사용 허가와 정확한 제품 모델을 함께 확보한 사진은 0건이다. 실제 사진 적용, 공개 배포, main 병합, 광고·색인·호환성 승인·공개 반응 집계는 수행하지 않았다.

[실제 출시 후보 검수](RELEASE_CANDIDATE_REVIEW_20261015.md)와 [제품 이미지 사용권 조사](MONITOR_IMAGE_RIGHTS_RESEARCH_20261015.md)를 독립 세션으로 진행한 뒤 통합했다. 30개 개별 이미지의 권리가 검증됐다고 해석하지 않는다.

## 반영한 변경

- `web/monitor-purpose.css`: 숨겨졌던 검색 label을 지속적으로 보이게 했다.
- `web/monitor-v3.html`: label은 `모니터 검색`, 미리보기 안내는 이름 있는 region으로 표현한다. 기존 경고 내용과 noindex는 유지한다.
- `tests/e2e/release-candidate.spec.js`: 입력 후에도 보이는 label, axe label-title-only, 미리보기 landmark·region, noindex 회귀 검사 2개를 데스크톱·모바일에서 실행한다.
- 두 세션 보고서 및 현재 진행 문서만 추가·갱신한다. 제품 정보·후기·뉴스 목록·이미지 파일·원본 스키마는 변경하지 않는다.

원격 테스트 수는 사용자 변경을 커밋하지 않는 차이 때문이다. 테스트 통과는 제품 실측·공식 호환성 승인·사진 권리 확보를 뜻하지 않는다. 최종 커밋과 정확한 HEAD의 GitHub CI 결과는 완료 응답 및 해당 브랜치 Actions 실행에 연결한다.

## 이미지와 남은 위험

30종 모두 기존 형태 예시를 유지한다. 삼성 자체 제작 뉴스룸 자료의 재사용 안내도 정확한 현재 SKU 사진·제작 주체와 연결되지 않아 적용하지 않았다. 다른 지역 약관을 한국 SKU 승인이나 모든 미디어 자산의 허가로 확대하지 않는다. 권리자 연락·신청·다운로드·핫링크·접근 제한 우회는 하지 않았다.

조사 중 `lgnewsroom.com`은 예상과 다른 축구 콘텐츠를 반환해 근거에서 제외했다. 기존 data/web/scripts에는 해당 도메인 참조가 없었다. 도메인 소유권 변경이나 침해 여부는 단정하지 않는다.

외부 후기 29종 35링크와 LS34C650UEEXXY 보류를 유지한다. 지역 SKU·문서 충돌·미확인 값·공개 UNKNOWN 정책을 바꾸지 않았다. 접근성 자동 검사 통과는 모든 보조기기 사용성이나 외부 링크의 미래 가용성을 보장하지 않는다.

## 사용자 결정이 필요한 공개 단계

현재 작업에서는 제외했다. 공개 제품의 지역 범위, 도메인·호스팅·출시 승인, 사진 허가 자료 또는 직접 촬영본, 쿠팡 등록·실제 광고, 공개 반응 집계 운영 정책이 남아 있다. 댓글은 후순위로 유지한다. 승인 전까지 로컬/noindex 상태를 유지하며 동일 SKU 후기나 권리 조사에 근거 없는 재시도를 반복하지 않는다.
