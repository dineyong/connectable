## 원본 보존과 출처

## 근거 유형·상업성의 수용 경계

- `specs`는 퀘이사존 편집부·판매 행사·사용자 인용 등 2차 자료다. 공식 제조사 원문에 전건 연결되지 않았으므로 official_specs에 쓰지 않는다. 예: 32UN650의 제원 출처는 판매자 행사 글이다.
- measurements 24건은 자유 형식 13건(metric/value)과 editorial_measurement 표기 11건(text)으로 구조가 다르다. condition 8건, method 5건만 있으며 창 크기·HDR/SDR·오버드라이브·측정 도구·리비전 등을 다시 확인해야 한다. 27GS95QE 밝기 요약과 제조사 응답시간을 공통 필터 값으로 바꾸지 않는다.
- user_pros/cons와 editorial_pros/cons는 별도 개수만 인덱싱했다. 편집부 평가, 사용자 질문, 구매했지만 미사용, 비교 사용, 문제 제보, AS 이견을 같은 제품 후기나 객관적 결함률로 세지 않는다. 보강 29건에는 purchase_report_no_usage 1건이 있다.
- 보강 상업성 주장은 미확인 22, 판매 행사 언급 3, 후기 이벤트 명시 3, 이벤트 아님이라는 작성자 진술 1이다. 마지막 항목도 독립 비협찬 인증이 아니다. 상세 자료에도 후기 이벤트·총판 행사·파트너 핫딜이 포함된다.
- 과거 가격은 쿠폰·카드·포인트 체감가·중고·행사가·실결제액·구매가 범위를 분리해야 한다. 숫자 46건도 현재가가 아니다. intake에는 가격 금액 자체를 복사하지 않고 기록 개수만 남겼다.

## 산출물과 검증

intake는 상세 75 + 보강 29 + 목록 594 = **698개 후보**다. P1 17건(기존 공식 후보/기존 후기 URL), P2 87건(새 상세·후기 조사), P3 594건(목록 발견)이다. 우선순위는 구매 추천 순위가 아니다. sources는 제공 근거 142 + 목록 페이지/상세 페이지 2 + 기존 문제 글 표본 1 = 145개다.

후보에는 원본 위치, 정확 표기, 출처 ID, 매핑 후보/uncertain, 기존 후기의 exact label/URL 참조, 접근 주장과 제한만 저장한다. 공식 사실 값·원문 요약·가격을 대량 복제하지 않는다. source direct_check는 특정 범위만 확인하므로 그 출처를 참조하는 후보의 사실 전체를 승격하지 않는다.

검증 명령:

```sh
python3 scripts/validate_quasarzone_intake.py
python3 -m unittest tests.test_quasarzone_intake -v
```

17개 테스트 통과. 공개 승격, 자동 동치, 가짜 직접 확인/범위, dangling 참조, 중복 ID, 위험 URL/인코딩, 현재 가격/PII 복사, 전체 경로 저장, 목록 상세 승격, 통계 불일치, 중복 JSON 키·NaN·Infinity 거부를 확인했다. 기존 사양/후기 파일 해시가 바뀌면 intake 재생성과 매핑 재검토를 요구한다. 검사 통과는 원문 사실의 승인이나 공개 권리 확보가 아니다.
