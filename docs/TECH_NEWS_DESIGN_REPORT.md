# 테크 소식 디자인 및 저장 목록 안내

2026-10-11. 브랜치 `codex/monitor-purpose-design`. [승인 디자인](MONITOR_PURPOSE_DESIGN_REPORT.md)에 맞춰 뉴스 보조 화면을 정리했다. 이 보고서는 화면 변경 기록이며 뉴스 원문 재검증·공개 승인 기록이 아니다.

## 변경

- 회녹색 배경, 녹색 타이포그래피, 노란 제목 강조와 재열람 버튼을 적용했다. 데스크톱 2열·모바일 1열 카드, 초점 표시·본문 바로가기·44px 조작 높이를 제공한다.
- 기존 `/` 링크를 `monitor-v3.html`로 변경하고 구매 가이드·현재 메뉴를 표시한다.
- 저장된 목록과 수집 시각을 앞에 표시한다. ‘목록 다시 보기’는 서버 저장 목록 재열람이며 새 기사 수집 요청이 아님을 명시한다. 실시간 수신·현재 수집 프로세스 실행 여부를 추정하지 않는다.
- 출처 수집 상태는 접어 읽을 수 있으며, 마지막 수집 때의 상태와 현재 접속 여부를 구분한다. STALE 및 마지막 성공 시각을 보존한다.
- 필터 적용 후 실제 표시 가능한 카드 수를 알린다. 잘못된 출처 URL이 전체 화면 스크립트를 중단하던 경로를 방어하고 유효한 다른 항목은 유지한다. 알 수 없는 시각·출처 유형·수집 상태를 확정 정보로 바꾸지 않는다.
- 데이터 전체가 없거나 sources 배열이 없는 경우 오류를 표시하고 분류 조작을 비활성화한다. 다시 읽기와 탐색 링크는 남긴다.

## 검증

별도 8889 포트의 임시 Playwright 설정으로 기존 `tests/e2e/tech-news.spec.js`와 신규 [디자인 테스트](../tests/e2e/tech-news-design.spec.js)를 실행했다. 데스크톱·모바일 **12개 통과(8.6초)**. 기존 필터·제목 텍스트 삽입·안전한 링크·접근성·가로 넘침 검사와 새 탐색/저장 상태/잘못된 데이터 검사를 포함한다.

첫 실행 10/12 이후 접근성 검사에서 푸터 링크의 시각적 구분과 미리보기 띠의 landmark 누락을 발견했다. 밑줄·이름 있는 region으로 수정 후 12/12를 재확인했다. 테스트 삭제나 기대값 완화는 하지 않았다. 전체 회귀 결과는 통합 작업 보고서에서 기록한다.

## 보존과 경계

[뉴스 원본](../data/news/tech_news.json), [파생 뉴스 JS](../web/tech-news-data.js), 수집기와 뉴스 서버는 변경하지 않았다. 추가 외부 요청·예약 실행·기사 수집을 수행하지 않았다. 기사 전문·이미지·번역·추천 점수도 추가하지 않았다. `noindex,nofollow` 및 로컬 검토 상태를 유지한다.

소스 이용 조건 검토, 사람의 공개 검수, 독립 매체 추가, 운영 갱신 상태를 전달하는 서버 계약은 후속 범위다. 클라이언트의 호스트 비교는 원본 검증기를 대체하지 않으며 리다이렉트를 실시간 확인하지 않는다. 이번 작업은 공개 배포·광고·제휴 활성화를 포함하지 않는다.
