## 1. 서비스 정의

사용자가 자신의 노트북과 연결하려는 모니터 및 연결 장치를 선택하면,
공식 제품 사양·인터페이스 규격·실사용 사례를 근거로 다음을 알려주는
한국어 호환성 판정 서비스다.

- 연결 가능 여부
- 가능한 해상도와 주사율
- 외장 모니터 수 제한
- 필요한 케이블·어댑터·허브·독
- USB-C 단일 케이블 영상 출력 가능 여부
- USB Power Delivery 충전 가능 여부와 제한
- DisplayLink 등 우회 방식 필요 여부
- 같은 조합의 실제 사용자 성공·실패 사례

서비스의 핵심 결과는 상품 추천이 아니라 **근거가 있는 호환성 판정**이다.
상품 추천과 제휴링크는 판정 이후 필요한 해결 방법으로만 제공한다.

## 2. 해결하려는 사용자 문제

### 핵심 문제

사용자는 노트북, 모니터, 케이블, 독 각각의 사양은 찾을 수 있지만,
서로 다른 제조사의 제품을 함께 연결했을 때 실제로 동작하는지는 쉽게
판단하기 어렵다.

### 대표 질문

- 내 맥북은 이 모니터에서 4K 60Hz를 출력할 수 있는가?
- USB-C 케이블 하나로 화면 출력과 충전을 동시에 할 수 있는가?
- 외장 모니터 두 대를 확장 모드로 사용할 수 있는가?
- 어떤 케이블 또는 도킹 스테이션이 필요한가?
- 규격상 가능하다고 나오는데 실제 사용자도 성공했는가?
- 연결은 되지만 주사율, HDR, 색 형식 또는 충전 출력이 제한되는가?

## 3. 최초 목표 사용자

다음 조건을 가진 한국 사용자를 우선한다.

- Apple Silicon 맥북을 사용하거나 구매할 예정인 사람
- 외장 모니터를 처음 연결하는 사람
- 4K 또는 고주사율 모니터의 성능을 제대로 사용하려는 사람
- 듀얼 모니터, 클램쉘 또는 원케이블 구성을 만들려는 사람
- 허브·독·케이블을 구매하기 전에 호환성을 확인하려는 사람
- 연결 실패 후 원인을 진단하려는 사람

## 4. MVP 지원 범위

### 4.1 소스 기기

- Apple Silicon 기반 MacBook Air
- Apple Silicon 기반 MacBook Pro
- 각 제품의 칩 계열과 화면 크기·출시 세대를 구분한다.

초기 데이터 수집 과정에서 공식 사양을 확인할 수 없거나 모델 식별이
모호한 제품은 공개 판정 대상에서 제외한다.

### 4.2 디스플레이

- 한국에서 유통되는 LG·삼성·Dell·알파스캔 등 주요 모니터
- FHD, QHD, 4K, 5K, 6K
- 60Hz, 75Hz, 120Hz, 144Hz 이상 주요 주사율
- HDMI, DisplayPort, USB-C, Thunderbolt 입력
- USB-C Power Delivery 및 허브 기능

초기 공개 제품 수는 검색 수요와 공식 자료 품질을 기준으로 30개 내외로
제한한다.

### 4.3 연결 장치

- USB-C to USB-C 케이블
- USB-C to DisplayPort 케이블
- USB-C to HDMI 어댑터·케이블
- HDMI 및 DisplayPort 케이블
- USB-C 허브
- Thunderbolt 독
- DisplayLink 독·어댑터

MVP 판정은 먼저 제품 유형과 규격을 기준으로 제공한다. 개별 판매상품은
공식 사양과 재고·제휴 가능성을 검증한 경우에만 추천한다.

### 4.4 판정 항목

- 물리적 연결 가능 여부
- 네이티브 영상 출력 가능 여부
- 요구 대역폭 충족 여부
- 최대 해상도와 주사율
- 외장 디스플레이 최대 수
- 미러링과 확장 모드 차이
- 클램쉘 조건
- MST 지원 및 Apple Silicon 제약
- DSC 필요 여부
- DisplayLink 필요 여부와 소프트웨어 조건
- USB-PD 충전 가능 여부
- 충전 출력 부족 가능성
- 확인된 실제 성공·실패 사례

## 5. MVP 제외 범위

다음은 데이터와 운영 능력이 확보된 이후 검토한다.

- 모든 Windows 노트북 지원
- 데스크톱 그래픽카드와 메인보드 조합
- TV, 프로젝터, 콘솔 게임기
- 실제 게임 FPS 예측
- 색 정확도와 캘리브레이션 평가
- eGPU 구성
- 오디오·HDCP·DRM의 모든 예외 판정
- 제품 가격 추적
- 비공개 API 또는 접근 제한 페이지 수집
- 사이트 차단을 우회하는 자동 크롤링
- 사용자에게 구매 보상 또는 후기 작성 리워드 제공

## 6. 판정 상태

내부적으로 다음 상태를 사용한다.

| 코드 | 의미 | 사용자 표시 |
|---|---|---|
| `VERIFIED_COMPATIBLE` | 공식 근거와 실사용 근거가 모두 충분함 | 검증된 연결 가능 |
| `COMPATIBLE` | 공식 사양과 규격상 가능함 | 연결 가능 |
| `CONDITIONAL` | 특정 케이블·독·설정이 필요함 | 조건부로 가능 |
| `LIMITED` | 연결되지만 기능 또는 성능이 제한됨 | 제한적으로 가능 |
| `INCOMPATIBLE` | 공식 제한 또는 규격상 불가능함 | 연결 불가 |
| `UNKNOWN` | 판정할 근거가 부족함 | 아직 확인되지 않음 |
| `CONFLICT` | 공식 정보와 실사용 사례가 충돌함 | 추가 확인 필요 |

판정에는 반드시 근거, 확인일, 신뢰 수준을 함께 저장한다.

## 7. 사용자 생성 데이터 범위

### 구조화된 연결 결과

- 성공
- 제한적으로 성공
- 실패

등록 시 기기와 연결 장치, 해상도, 주사율, 충전 여부, 운영체제 버전,
확인 날짜를 구조화해 저장한다.

### 일반 댓글

질문과 대화는 별도 댓글 기능으로 제공한다. 일반 댓글 내용은 검증 없이
호환성 판정 근거로 사용하지 않는다.

### 공개 원칙

- 초기에는 관리자 승인 후 공개한다.
- 개인정보와 홍보 링크를 제거한다.
- 판매자 또는 이해관계가 있는 사용자는 관계를 표시해야 한다.
- 단일 후기는 공식 사양을 자동으로 뒤집지 않는다.
- 여러 독립 사례가 일치할 때 실사용 신뢰도를 높인다.

## 8. 수익화 범위

### MVP

- 판정 결과에 필요한 케이블·허브·독·모니터의 제휴링크
- 링크 위치와 조합 단위 클릭 추적
- 제휴 관계 명확한 고지

### 트래픽 확보 이후

- 정보성 가이드 페이지의 제한적 광고
- 제조사·브랜드 직접제휴
- B2B 장비 구성 또는 대량구매 문의 연결

판정 도구와 핵심 결과 영역에는 사용자 판단을 방해하는 광고를 우선
배치하지 않는다.

## 9. 정확성 및 안전 원칙

- 생성형 AI 출력만으로 제품 사양을 확정하지 않는다.
- 공식 출처를 우선하고 원문 URL과 확인일을 기록한다.
- 판매 페이지의 문구만으로 호환 판정을 확정하지 않는다.
- 불확실한 경우 긍정 판정 대신 `UNKNOWN`을 반환한다.
- 소프트웨어·펌웨어·운영체제에 따른 조건을 별도로 기록한다.
- 제품 사양 변경과 정정 이력을 보존한다.
- 판정은 구매 보증이 아니라 확인 가능한 근거에 기반한 안내임을 고지한다.

## 10. MVP 성공 기준

출시 후 초기 검증 기간에 다음 지표를 본다.

| 지표 | 1차 목표 |
|---|---:|
| 공식 출처가 연결된 제품 | 50개 이상 |
| 공개 가능한 검증 조합 | 100개 이상 |
| 실제 사용자 연결 결과 | 50개 이상 |
| 월 검색 방문자 | 3,000명 이상 |
| 판정 완료율 | 40% 이상 |
| 제휴링크 클릭률 | 15% 이상 |
| 잘못된 판정 신고율 | 5% 미만 |

초기 목표는 광고수익이 아니라 정확한 조합 데이터와 사용자의 반복 사용을
검증하는 것이다.

- 데이터 출처
- 정확성 위험
