## 검수 사항

- UQ-0011: HDMI 직후 TEMPORARY 정상과 다음 날 RECURRENT 끊김을 recurrence_of로 연결했다. 여러 점검 목록의 내부 순서는 UNORDERED다. 향후 외장만 쓰는 클램쉘 계획을 실제 관측으로 만들지 않았다. HDMI 호스트 측은 UNKNOWN_GAP이다.
- UQ-0016: 클램쉘 외장 사용과 덮개를 연 뒤 내장 배율 문제를 분리했다. 내장 증상을 외장 해상도 관측으로 옮기지 않았다. 재부팅은 질문 속 가능 조치이며 실행 시도가 아니다. 답변의 미러링 추측도 실제 모드로 만들지 않았다.
- UQ-0018: 단계별 실제 점검과 1920x1080 출력·2560x1080 무신호·최종 DP 정상 사용을 분리했다. 글의 나열은 RECONSTRUCTED_PARTIAL이며 실제 날짜는 미상이다. 썬더볼트3(DP 3.1) 혼용 표기는 notes로 보존하고 호스트 커넥터는 UNKNOWN이다. 최종 픽셀 수·주사율은 목표에서 복사하지 않았다. 제목의 실패를 구성 종결로 자동 변환하지 않았다.
- UQ-0021: 직접 HDMI·허브·휴대용 화면 동시 연결의 낮은/높은 주사율·분리/재연결·최종 케이블 교체를 각각 보존했다. 휴대용 화면의 점등·독립 확장·대수를 추정하지 않았다. 2580x1440 오타 가능 표기는 메모만 보존하고 수정하지 않았다. 최종 144Hz는 작성자 댓글 근거이며 케이블 원인을 공식 사실로 확정하지 않았다. 타인의 DP 165Hz나 상품 추천은 제외했다. Windows 노트북 비교는 notes에만 남겨 다른 소스 실제 구성과 섞지 않았다.

모든 사례는 C/NEEDS_REVIEW/NO/NOT_CHECKED를 유지한다. 판매 링크 NO, 제휴·광고성 UNKNOWN으로 검토했다.
