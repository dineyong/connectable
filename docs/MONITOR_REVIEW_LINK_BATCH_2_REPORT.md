## 원문 검토와 데이터 경계

공개 페이지에서 정확 모델, 본인 사용 또는 전문 리뷰 소개, 광고·판매·제휴 고지를 확인한 링크만 DIRECT_CHECK로 기록했다. YouTube의 제목·펼친 설명·챕터 확인을 영상 전체 시청이나 측정 재현으로 표현하지 않는다. 검색 요약·플랫폼 자동 요약으로 사양을 채우지 않았다. 원문 본문·사진·썸네일·영상·작성자명·연락처를 복제하지 않았다. URL의 블로그 식별 경로는 원문 접근 주소로만 유지한다.

[링크 원본](../data/research/monitor-review-links.json)이 후기 정보 기준 파일이며 [모델·URL 검토 바인딩](../data/research/monitor-review-link-bindings.json)은 신규 플랫폼의 정확한 모델 연결 근거다. 후보 임시 파일은 통합 후 저장소에 중복 기준으로 남기지 않았다. 파생 데이터는 두 기준 자료를 검증한 뒤 생성한다.

## 구현 및 검증

- 동적 상세와 JavaScript 없는 정적 제품 문서에 영상/블로그 원문을 표시한다. 모든 원문 링크는 `target="_blank" rel="noopener noreferrer"` 및 새 창/탭 안내를 사용한다.
- 등록되지 않은 모델·URL 연결, 위장 호스트, 추가 query, 잘못된 영상 ID, 포트·인코딩·경로 이동·누락 근거·중복 URL을 거부한다. 기존 RTINGS 고정 모델 경로 및 퀘이사존 원본 후기 참조 검증을 유지한다.
- Python 전체: **598개 통과**. 신규 회귀 6개를 포함한다. 의도적인 잘못된 입력 테스트에서 출력되는 FAIL 메시지는 정상 거부 결과이며 전체 종료 결과는 OK다.
- 브라우저 전체: **202개 통과(1.2분)**. 로컬 사용자 미커밋 테스트14개가 포함되어 원격 기준은188개다. 새 탭 실제 열림·opener 분리·위조 링크 차단·모바일 표시를 검사한다.
- 후기 생성물, 정적 30제품 문서, v3 표시 데이터, 제품 준비도 생성물 검사 통과. 로컬 HTML/메타데이터 경로, 공식/후기/시장 데이터 분리 및 퀘이사존 격리 검증 통과.
- 사용자 변경 4파일, 공식 사양·기존 커뮤니티·한국어/영어/v2 질문 코퍼스는 작업 전후 SHA-256 동일. 기존 후기 5개 객체도 동일. 링크 ID·정규화 URL·정확 모델 참조, 연락처/비밀값 및 diff를 검사한다.
