- 최종 커밋: 이 문서를 포함한 커밋으로 식별한다.

## 표시 변경

모달 상세와 비교표의 JSON 객체 표현을 항목별 한국어 라벨과 줄바꿈으로 변경했다. 예를 들어 HDMI 값은 `버전: 2.0`, `개수: 2`로 표시한다. 방향을 명시하지 않은 포트 수를 입력 수로 해석하지 않는다. 복합 값의 외부 단위는 마지막 숫자에 붙이지 않고 별도 단위 줄에 표시한다. 정격·최대·문서 지역·출처·미확인 안내는 기존 영역에서 유지한다.

독립 상세 페이지 30개도 같은 포맷을 사용한다. Python/JavaScript 표시기의 실제 원본 전체 값과 단위 결과를 교차 검증하는 테스트를 추가했다. 표시기는 원본 fact, 검색/필터, 차이 비교 기준, 승인 상태를 변경하지 않는다.

## 보존 규칙

- 숫자·문자열·배열 순서, 스탠드 포함/제외, 원문 조건을 보존한다.
- 제조사 추정 표기는 한국어와 원래 토큰을 함께 유지한다.
- 알려지지 않은 키는 원래 이름으로 표시한다. 원문 조건을 자동 번역하거나 누락하지 않는다.
- 단위 환산, 모델 동일성 추정, 공식 검토 승인, 호환성 판정은 하지 않는다.
- HTML로 보일 수 있는 값은 이스케이프하며, 악성 문자열을 실제 이미지나 이벤트로 실행하지 않는 회귀 테스트를 추가했다.
- 기존 원본 데이터와 미커밋 사용자 작업은 커밋 대상에서 제외한다.

## 검증

최종 결과는 아래 실행 기록을 따른다. 초기 전체 브라우저 실행은 141 통과 / 3 시간제한 실패였다. 세 실패는 기존 데스크톱 테스트의 30초 제한이며 단언 실패가 아니었다. 동시 작업 부하 가능성을 확인하기 위해 테스트 제한·단언을 변경하지 않고 workers=2로 전체 재실행했다.

## 남은 범위

영문 제조사 조건과 배열 표기는 의도적으로 보존했다. 자연어로 단순화하려면 항목별 의미 검토가 필요하다. 실제 제품 사진 사용권, 한국 SKU 동일성, 공개 댓글 운영, 광고·제휴·배포 승인은 별도 과제다. 이번 작업은 로컬 표시 개선이며 main 병합이나 공개 배포를 하지 않는다.
