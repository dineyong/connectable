# 외부 후기 원문 링크 UI

2026-10-11. 제품 사양 탐색 화면의 기존 디자인과 공식 사양 표시를 유지하면서 제품별 외부 리뷰 동선을 추가했다. 원문 링크는 `target="_blank"`, `rel="noopener noreferrer"`로 열며 실제 창·탭 선택은 브라우저 설정에 따른다.

## 표시와 경계

- [상세 대화상자](../web/monitor-v3.html)와 JavaScript 없이 읽는 정적 제품 문서에 별도 **외부 후기 원문** 구역을 제공한다.
- 사이트·전문 리뷰/개인 사용기 유형·확인일·직접 작성한 짧은 안내·광고/판매/제휴 검토 상태를 표시한다. 작성자 닉네임과 외부 사진·썸네일은 표시하지 않는다.
- 공식 사양·제품 점수·호환성 승인이 아니며 한국 판매 SKU 동일성을 보장하지 않는다고 안내한다. 내부 모델 검증 마커를 사용자에게 승인 배지로 표시하지 않는다.
- 연결한 리뷰가 없으면 명확한 빈 상태를 표시하고 다른 모델의 리뷰를 가져오지 않는다. 웹 데이터 로딩 실패는 후기 로딩 실패로만 안내하며 제품 사양은 유지한다.
- 영상·블로그 링크를 아직 확보하지 않은 상태에서 예시 링크를 생성하지 않는다. 뉴스 원문 링크는 이미 같은 새 탭 속성을 사용하고 있다.

## 검증과 생성

[정적 페이지 생성기](../scripts/build_monitor_pages_v3.py)는 [후기 데이터 생성기](../scripts/build_monitor_review_links.py)의 읽기 전용 `build()`를 호출해 원본 참조·모델·URL 검증을 수행한다. 생성 시 후기 요약을 공식 fact로 합치지 않는다. `--check`는 파일을 수정하지 않고 생성 결과가 맞는지만 검사한다.

웹 표시도 HTTPS·정확한 사이트 호스트·후기 경로와 `EXACT_DOCUMENT_MODEL` 범위를 확인한다. 인증정보, 쿼리, 프래그먼트, 백슬래시·인코딩·제어문자를 포함한 URL과 불확실한 유형은 링크로 표시하지 않는다. 텍스트는 HTML 이스케이프하며 긴 제목이 모바일 화면을 넘지 않도록 한다.

[브라우저 회귀 테스트](../tests/e2e/monitor-review-links.spec.js)는 데스크톱·모바일에서 정상 원문 링크 속성, 유형과 광고 안내, 모델별 빈 상태, 누락 데이터, 악성 URL·불확실한 모델 범위, HTML 주입 방지와 긴 제목 줄바꿈, 정적 문서 링크를 검사한다. 전체 실행 결과는 통합 담당자가 최종 배치 보고서에 기록한다.

## 남은 한계

정적 링크는 원문이 삭제·비공개로 바뀌거나 내용이 수정될 수 있다. 확인일은 해당 시점의 확인 기록이며 지속 접근 보장은 아니다. 개인정보·본문·이미지 수집 및 외부 사이트 실시간 조회 기능은 추가하지 않았다. 공개 승인·호환성 승인·평점·제휴 링크 활성화도 추가하지 않았다.
